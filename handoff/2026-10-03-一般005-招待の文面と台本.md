# 一般クエスト #005「SchoolParkを、誰かに届ける」— 配る文面と台本

2026-10-03 作成。コードの変更ではなく、そのまま使う文章です。

---

## 0. 先に、やってはいけないこと

#005 の「参加のルール」に書いてあるとおりです。**ここを外すと、完走が認められません。**

- EMUER を「儲かる」「値上がりする」「稼げる」のように**投資として書かない**
- 「必ず増える」「もらえる額が上がる」など、**金額の約束をしない**
- 招待は、**相手が自分で決めて発行したものに限る**（代わりに発行しない）

言ってよいのは「**残る**」ことで、「**増える**」ことではありません。
以下の文面はすべてこの線を守って書いてあります。**そのまま使えば安全です。**

---

## 1. 招待リンクの出し方

SchoolPark を開く → **⚙️ 設定** → **🔗 招待リンク** → 「リンクを出す」

```
https://schoolpark-emu.vercel.app/invite.html?ref=（あなたの合言葉）
```

パスポートを作った直後にも、同じものが出ます。

このリンクから入った人がパスポートを作ると、**サーバーが自動で数えます。**
相手の名前を報告する必要はありません。運営の照合も自動です。

## 2. 投稿文テンプレ

`[リンク]` を自分の招待リンクに置き換えてください。

## 3.「3分でPassport」の台本

### 3-1. 縦動画（9:16、30〜60秒）

| 秒 | 画面 | 声／字幕 |
|---|---|---|
| 0–4 | タイトル。黒地に白文字 | 「やったことが、残る場所をつくりました」 |
| 4–9 | 招待リンクを開いたところ | 「リンクを開きます。ここまで0秒」 |
| 9–16 | 「SchoolPark をはじめる」を押す → ログイン画面 | 「LINE か Google でログイン。新しい登録は要りません」 |
| 16–24 | 名前を入れて発行 | 「名前を入れて、発行。これだけです」 |
| 24–34 | パスポートの番号が出る | 「あなたの番号ができました。この番号は変わりません」 |
| 34–44 | 星空の画面 | 「ここから先、やったことがここに積み上がっていきます」 |
| 44–52 | 「次はあなたが届ける番」の画面 | 「受け取ったら、次は誰かに渡してください」 |
| 52–58 | 締め。リンクを出す | 「3分です。ウォレットは要りません」 |

**撮るときの注意**

- 実際の画面を録る。作り物の画面は使わない
- 金額（100 EMUER など）は**映さない**。映ると投資の話に見える
- 自分の番号は映してよい。他人の番号・名前は映さない
- 音声なしでも伝わるよう、字幕を必ず入れる

### 3-2. 画像3枚のガイド（動画を撮らない場合）

同じ内容を3枚で。各画像に1行だけ文字を入れます。

1. **リンクを開く** — 「3分で終わります」
2. **LINE か Google でログイン** — 「新しい登録は要りません」
3. **名前を入れて発行** — 「あなたの番号ができました」

キャプション：

```
SchoolPark のパスポートの作り方です。3分、ウォレット不要。
やったこと・学んだことが、ここに積み上がっていきます。
[リンク]
```

## 4. 創業者の完走を、そのまま見本にする

#005 は「最初の完走者＝創業者」と決めてあります。
**専用の見本を別に作る必要はありません。** 自分の報告3本をそのまま公開の見本にします。

書くときの形だけ決めておきます。

### ① 開始宣言（「やってみた」）

```
#005 を、発信で進めます。
X に SchoolPark の紹介を1回、招待リンク付きで投稿します。
今日から14日以内に出します。
```

> **どちらで進めるか（発信／招待）を必ず書く。** これが宣言です。

### ② 中間報告（「つまずいた」）

```
文面を3回書き直しました。
「もらえるもの」を並べると、どうしても投資の話に見えてしまう。
「何が残るか」だけ書いたら、やっと自分でも読める文になりました。
```

> つまずきを書くのが本題です。うまくいった話だけだと見本になりません。

### ③ 最終報告（「気づいた」）

```
投稿しました（URL）。
人に説明しようとすると、自分が何をつくっているのかが一番はっきりする。
説明できない部分は、まだ決まっていない部分でした。
```

### ④ 知恵カード（1枚）

```
元の知識：誰かに説明すると理解が深まる、という話
通した経験：#005 で SchoolPark の紹介文を書いて投稿した（3回書き直した）
残った一文：説明できない部分は、まだ自分が決めていない部分だった
```

## 6. 数字の見通し

招待での完走は**1人1件**です。100人が完走しても積み上がるのは100件で、
年末目標の 500〜1,000件には届きません。

届かせるのは、**招待された人が次の招待者になる連鎖**です。
パスポートを発行した直後に「次はあなたが届ける番」を出すようにしてあるので、
1人 → 2人 → 4人と伸びれば届きます。

伸びないときに効く手は、この順です。

1. **現場で発行する** — 解剖フェス（特殊 #002）、カフェ会（#004）の冒頭に「その場で発行タイム」を5分
2. **完走後も数える** — 2人目以降は報酬を増やさず、パスポートに「届けた人数」として出すだけにする
3. **見本を増やす** — 完走した人の報告3本を、本人の許可を取って並べる
