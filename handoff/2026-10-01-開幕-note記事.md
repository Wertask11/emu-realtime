# SchoolPark を開きます

## 何を作ったのか

SchoolPark は、やったことが記録に残る場所です。

DAO と名前は付いていますが、話し合うための場所ではありません。
クエストを受けて、実際にやって、報告を残す。それだけの場所です。

ギルドが5つあります。

| | |
|---|---|
| LEARN | 知識を、やってみるに変える。 |
| WORK | 貢献を、仕事と次の機会へ。 |
| PLAY | 遊びから、挑戦と出会いを。 |
| CONNECT | 孤立ではなく、つながりながら自立する。 |
| WEB3 | 信用・価値・実績を持ち運べる社会基盤をつくる。 |

言葉の意味はこうです。

- **ギルド** … 同じ目的を持つ人が集まる活動領域
- **議題** … みんなで考え、決めること
- **クエスト** … 決めたこと・試したいことを実際にやる

---

## やること

1. SchoolPark Passport を作る
2. クエストを受ける
3. やる
4. 「やってみた」「つまずいた」「気づいた」を残す
5. 知恵カードを1枚置く
6. 運営が確認して、完走

報酬は EMUER・JPYC・円 のいずれかです。
信用スコアが増え、パスポートに記録が残り、星空に星がひとつ増えます。
完走の証明書（NFT）も受け取れます。譲渡はできません。自分の記録だからです。

---

## 3つ、はっきりさせておきます

### ① 出したあとに、題名も報酬も締切も変えられません

システムがそうなっています。運営にも変えられません。

受けた人が見た条件が、あとからすり替わらないようにするためです。
「こういう話だったはずだ」が起きない作りにしました。

### ② 知恵は、完了したクエストからしか生まれません

意見や感想からは生まれません。
やり終えた人だけが、知恵カードを置けます。

読んだこと・思ったことではなく、やってみて分かったことが残ります。

### ③ 票は、1つのパスポートにつき1票です

取り消しも、書き換えもできません。
入れる前に考える、という形にしています。

---

## EMUER について

EMUER は、やったことに対して渡すものです。

値上がりを期待して持つものではありません。
そういう使い方を想定していませんし、そう案内することもしません。

受け取ったぶんは雑所得にあたります。
ほかの所得と合わせて年20万円を超えると、確定申告が要ります。

先に書いておきます。あとから知って困る人が出ないように。
