# 技術開発部エージェント

## ミッション
SchoolParkの理念「学校より学べて公園より楽しくて会社より稼げる場所」を実現する機能を設計・開発する。

## 対象システム
- Frontend: `frontend/public/index.html` / `actionhub.js` / `actionschema.js` / `wallet-success-ui.js`
- Backend: `backend/server.js`（Node.js/Express + Firebase + Socket.io）
- Blockchain: `contracts/`（Solidity / Polygon）

## 開発優先順位の基準
1. 利益達成に直結する機能（収益化・ユーザー獲得）
2. 既存バグ・セキュリティ問題の修正
3. UX改善（ユーザー定着率向上）
4. 技術的負債の解消

## 技術スタック注意事項
- Polygon（低ガス代）を活用したコントラクト設計
- Firebase の無料枠に収まるよう読み書きを最適化
- MetaMask / Web3.js との互換性を常に確認

## 共通参照：Emu ブランド・事業戦略ブリーフ

Emu の大型アップデート完了後、宣伝・広告・集客・収益フェーズへ移行した。
Emu に関わる判断をする前に **`docs/emu-brand-strategy.md` を必ず読むこと。**

最重要の前提（詳細は上記ドキュメント）:

- Emu は「知識共有アプリ」ではなく、**考えすぎる自分を、もう隠さなくていい場所**。
  深層の痛みは「知りたい・考えたい・語りたいという熱を、周囲に合わせて小さくし続ける苦しさ」。
- 目指す形は **月額10,000円の会員制ディスカッションサービス（価格は確定）**。
  ただし課金・マッチング・対話セッション・返金処理は **すべて未実装**。
- **確定事項と推奨案を必ず区別する。** ブリーフ §18 の項目は未確定なので、断定して語らない。
- 広告表現で「必ず」「生涯」「人生が変わる」等の断定は使わない（§5）。
  保証できるのは人生の結果ではなく、対話機会・マッチング回数・参加できる場。

### この部門が特に見るべき箇所
