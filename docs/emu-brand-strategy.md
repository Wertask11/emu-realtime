# Emu ブランド・事業戦略ブリーフ

最終更新: 2026-08-12 / 情報源: オーナー（合同会社型DAO SchoolPark 代表）からの直接共有

Emu の大型アップデート完了を受けて、宣伝・広告・集客・収益フェーズへ移行する。
本ドキュメントは全部門エージェントの共通前提とする。**確定事項と推奨案（未確定）を必ず区別すること。**

一文要約：

> Emu は、映画・本・学び・知識について深く語りたいのに、周囲との温度差から自分の情熱を隠してきた人が、
> 同じ熱量を持つ相手と出会い、対話を通じて知識を使える言葉へ変える、月額1万円の会員制ディスカッションサービス。

## 1. 原点（創業者の没頭と怒り）

**没頭・偏愛**
- 知識を交換すること / 人と一緒に学ぶこと
- 映画を観た後に感想や考えを言い合うこと / 本について深く話し合うこと
- 意見をぶつけ合い、考えが深まる瞬間
- 切磋琢磨できる相手との関係

**怒り・苛立ち**
- Emu がまだ不人気であること
- 議論の楽しさに周囲がついてこないこと / 深く語り合える人がいないこと
- ライバルや切磋琢磨できる相手がいないこと
- 好奇心や情熱を出すと「面倒な人」として扱われる空気
- 学びが一人きりのインプットで終わってしまうこと

**届けたい価値**
ディスカッションの楽しさ / 個人間の知識共有 / 考えを自分の言葉にする体験 /
熱量の合う相手との出会い / 一人では到達できない学び / 好奇心を小さくしなくてよい居場所

---

## 2. 本質的な顧客課題

表面的には「知識共有の場所がない」「話し相手がいない」だが、**深層の痛みは次の一点**。

> 知りたい、考えたい、語りたいという自分の熱を、周囲に合わせて小さくし続ける苦しさ。

共通する感情：
- 人数ではなく、思考の深さや熱量が合わない孤独
- 考えすぎる自分への羞恥 / 好きなことを話しすぎた後の自己嫌悪
- 「意識が高い」「面倒くさい」と思われる恐怖 / 発言前に自分を止める自己検閲
- 未完成な意見を出せない不安 / 学んでいるのに変化していない焦り
- 同じ熱量を返してくれる相手への渇望
- 対話を通じて、自分の考えの価値を確かめたい気持ち

**ポジショニングの核**：Emu は知識共有アプリではなく、**考えすぎる自分を、もう隠さなくていい場所**。

## 3. 宣言文

**現在の宣言文（オーナー提示・要改善と評価済み）**

> 私は、もっと自由に学びたいのに周りが許してくれないで悩む情熱（学びたいという意思）をもつ人間のための、
> 知識の共有を個人間で行えるようにするアプリ「Emu」をつくった起業家です。

セグメントが広すぎるという評価。理由：
- 「自由に学びたい人」の範囲が広い
- 「周りが許してくれない」の状況が曖昧
- 「知識共有」が機能説明にとどまっている
- 顧客が「自分のことだ」と即断しにくい

**最有力の代替案（推奨・未確定）**

> 私は、映画や本に心を揺さぶられた夜、語りたいことが溢れているのに、話せる相手がいない人のために、
> 「面白かった」の先を語り合えるアプリ「Emu」をつくった起業家です。

## 4. 顧客セグメント候補（7案・最終決定は未確定）

最初の突破口として **1 が最有力**。

1. **映画や本について深く語る相手がいない人**（最有力）

   観賞直後の熱が冷める前に話したい / 作品を通して自分自身を理解したい
2. **知的好奇心を煙たがられる人**
   「意識高い」「また難しいことを考えている」「その話、長い」/ ひけらかしと誤解される / 興味のないふりをしている
3. **SNSでは深い話ができない人**
   長文を投稿前に消す / 強く断言しないと注目されない / 反論より雑に理解されるのが怖い / 未完成の考えを一緒に育てたい
4. **独学に限界を感じる社会人**
   保存するだけで終わる / 一週間後には説明できない / 収集が自己満足 / 初歩的な理解を見せるのが恥ずかしい
5. **勉強会で発言できない人**

6. **切磋琢磨できる仲間がいない人**
   応援だけでは足りない / 「その考えは甘い」と言ってほしい / 手の届くライバルが欲しい / 競い合って可能性を確かめたい
7. **好きなことを話しすぎて引かれる人**
   相手の表情を見て後から反省する / 好きなことを話すときだけ自分らしい / 同じ熱量を返してほしい /
   話しすぎではなく場所を間違えている

## 7. リスクリバーサル ★確定（2026-08-12）

> **確定した内容（実装済み・`docs/emu-membership-setup.md`）**
>
> 「語り合える一人」保証を採用。30日間で最低4回の対話機会を提供し、3回以上参加しても
> 「また話したい」と思える相手に一人も出会えなければ、**初月料金10,000円を全額返金**する。
> 判定は本人の評価と利用記録。申請期間は入会31日目から7日間、一人につき1回限り。
> 希望者には返金前に創業者が直接話を聞き、無料で対話を1回設定する（返金の条件ではない）。
>
> **追加5,000円の補償は取りやめた。返金は初月料金の全額のみ。**
> 対話の相手は**創業者本人**が務めるため、マッチングのアルゴリズムは作らない。
>
> 以下は決定に至るまでの検討記録。**下の「最低4回の対話保証（1回2,500円換算）」と
> 「追加5,000円補償」は採用していない。** 顧客向けの文面は
> `frontend/public/guarantee.html` と利用規約 第5条の3 が正。

### 検討記録（以下は不採用案を含む）

**前提：初月無料ではない。初月10,000円を先に決済し、条件を満たしても価値を届けられなければ返金する設計。**

基本の流れ：
1. 入会時に 10,000 円を決済
2. 30日間利用
3. 保証条件を満たしても価値ある相手に出会えなければ返金
4. 継続する場合は翌月も 10,000 円
5. 次回決済前の解約で翌月請求なし

### 「語り合える一人」保証【採用】
30日以内に「また話したい」と思える相手と出会えなければ、初月料金 10,000 円を全額返金。

条件案：初回入会者 / プロフィール完成 / 興味・関心テーマ登録 / 対話可能日時登録 /
30日間で3〜4回以上の対話に参加 / 対話後の評価に回答 / 無断欠席や重大な規約違反がない / 所定期間内に返金申請

判定基準：本人が「もう一度話したい」と評価した相手が一人もいない場合。
感情の証明は要求せず、**本人の評価と利用記録**で判断する。

### 最低4回の対話保証【不採用】
月4回の対話機会を提供できなかった場合、未提供回数分を返金（1回 2,500 円換算）。
3回なら 2,500 円 / 2回なら 5,000 円 / 0回なら 10,000 円全額。

### Emu 側の不履行に対する追加補償【不採用】
Emu 側の責任で対話機会を提供できなかった場合、全額返金に加えて 5,000 円を補償。
**「満足しなかった」という主観ではなく、Emu 側の提供不履行に限定する。**

### 創業者直結保証【採用・希望制】
30日間参加しても居場所が見つからなければ創業者が直接話を聞く。再マッチングしても解決しなければ全額返金。
初期フェーズでは顧客調査と改善を兼ねるため有効。

### 採用した最終構成 ★確定
> 30日間で最低4回の対話機会を提供します。
> 「また話したい」と思える相手に一人も出会えなければ、初月料金 10,000 円を全額返金します。
> 希望される方には、返金前に創業者が直接お話を伺い、相手を選び直して、もう一度無料で対話を設定します。

（検討段階にあった「Emu 側の不履行に対する追加5,000円補償」は**採用しない**と決定した。）

## 11. ログイン方法

**現行**：LINE / Google / ウォレット（MetaMask）

**技術的に利用可能**
Google / LINE / メール / 電話番号 / Sign in with Apple / TikTok Login Kit / Kakao / WeChat / Facebook / Naver / MetaMask 接続

**現状では非推奨・実装困難**

- **Talkin ログイン** — 顧客層の相性はよいが、第三者向け OAuth / OpenID Connect / Login API の公開を確認できず、
  現状「TalkinアカウントでEmuにログイン」は実装できない。運営との正式提携・API提供が必要。
  → **Talkin はログイン手段ではなく、集客・招待コード・ボイスルームでの体験会・イベント告知・公式提携の候補として有望。**
- **Instagram ログイン** — 集客・投稿・シェアとの相性はよいが、一般消費者向けログイン手段としては不適。
  Instagram は集客、TikTok は集客＋ログイン候補、Meta系ログインが必要なら Facebook Login を検討。
- **MetaMask** — 一般ログインと同列に置くと「暗号資産サービスに見える」「ウォレットが必要だと誤解される」
  「Web3に慣れていない人が離脱する」。**「その他の方法」に格納、またはログイン後の設定画面で「ウォレットを接続」**。

### Sign in with Apple
Webアプリでも技術的に利用可能。必要なもの：
Apple Developer Program（年間 99 米ドル）/ App ID / Web用 Services ID / 本番ドメイン / HTTPS /
登録済みリダイレクトURL / 秘密鍵と署名処理 / 非公開メールへの対応 / アカウント統合 / アカウント削除

判断：iPhoneアプリを展開するなら採用。当面Webだけなら Google・LINE・メールを優先。
Web向けAppleログインにも Apple プラットフォーム側のアプリとの関連付けが必要。

### 推奨ログイン画面
選択肢を並べず、**主要3つ＋「その他の方法」**。

日本向け：
```
［LINEで続ける］
［Googleで続ける］
［メールで続ける］
        その他のログイン方法
```
その他：電話番号 / Apple / TikTok / ウォレット

国別の推奨順：
- 日本：LINE → Google → Apple または メール
- 米国：Apple → Google → メール／電話番号
- 中国本土：WeChat → 電話番号 → Apple → QQ
- 韓国：Kakao → Google → Apple → Naver
- インドネシア：Google → 電話番号 → Facebook → Apple

**初期実装を小さくするなら Google / LINE / メール に絞り、電話番号と Apple は後から追加（推奨）。**

### メールログイン
パスワードではなく**マジックリンク**を推奨。
流れ：メール入力 → 一回限りのURL送信 → ユーザーがURLを開く → トークン検証 → セッション発行

必要：認証基盤 / メール配信サービス / 独自ドメイン / SPF・DKIM・DMARC / HTTPS / トークン生成・検証 /
再送制限 / 迷惑メール・バウンス管理 / メール変更・復旧手続き

セキュリティ：有効期限10〜15分 / 一回利用後は即時失効 / トークンを平文保存しない /
IP・メール・端末単位の回数制限 / アカウントの存在を推測できない応答 / 新端末ログイン通知 / 重要操作では再認証

### 電話番号ログイン
**SMS によるワンタイムコード**。

必要：国際SMS事業者 / 国番号対応 / E.164形式への正規化 / OTP生成・検証 / 配信結果管理 /
再送・試行回数制限 / SMS不正送信対策 / 電話番号変更 / 番号再割当てへの対応 / SMSが届かない場合の代替ログイン

保存例：表示 `090-1234-5678` / 保存 `+819012345678`

セキュリティ：OTP有効期限5分程度 / 入力試行最大5回程度 / 正解後に即時失効 / OTPを平文保存しない /
再送は30〜60秒待たせる / 電話番号・IP・端末・国ごとの送信制限 / 番号変更時に現在の方法で再認証 /
変更後に旧番号・メールへ通知 / 重要操作の一時制限 / **SMSを唯一の復旧方法にしない**

リスク：SIMスワップ / 電話番号の解約・再割当て / SMS盗聴 / 海外で届かない / SMS pumping /
VoIP・使い捨て番号 / 複数人で共有される番号

推奨形：**SMS OTP ＋ メールまたは Google／LINE による復旧**

## 12. 認証データの管理

一人のユーザーに複数ログイン手段を紐付ける。

**基本原則**
- メールや電話番号そのものを内部ユーザーIDにしない
- ランダムな `user_id` を主キーにする
- 認証情報とプロフィール情報を分ける
- 電話番号・メールを暗号化し、検索用に別の照合ハッシュを持つ
- OTP やマジックリンクの平文を保存しない
- **MetaMask の秘密鍵やシードフレーズを絶対に保存しない**

**想定テーブル**
- `users` — 内部ID / 表示名 / ステータス / 言語 / 国 / 年齢区分 / 作成・更新・削除日時
- `auth_identities` — ユーザーID / 認証プロバイダー / プロバイダー側ユーザーID / 暗号化メール /
  メール照合用ハッシュ / 暗号化電話番号 / 電話番号照合用ハッシュ / 確認日時 / 最終利用日時
- `auth_challenges` — 送信先のハッシュ / 認証目的 / トークンのハッシュ / 有効期限 / 試行回数 / 使用済み日時
- `sessions` — ユーザーID / リフレッシュトークンのハッシュ / 端末情報 / IP情報 / 有効期限 / 失効日時
- 監査ログ — ログイン成功・失敗 / OTP送信 / メール送信 / 連絡先変更 / 外部アカウント連携・解除 /
  決済情報変更 / アカウント削除 / 管理者による操作

**監査ログにも完全なメールアドレス、電話番号、OTP、アクセストークンは記録しない。**

### 重複アカウント対策
想定される問題：Googleで登録後にLINEで新規登録 / 電話番号でさらに別アカウント / 月額課金の重複 /
投稿やフォローが複数アカウントへ分散

## 20. 商品階段（フロント／ミドル／バックエンド）

月額1万円は「便利そうだから登録する」価格ではない。いきなり売るのではなく、顧客に次の順番で
気づいてもらう必要がある。

1. 自分は学べないのではなく、**語る相手がいない**
2. 対話すると、作品や知識の**理解が深まる**
3. **誰と話すか**で、対話の質が大きく変わる
4. 継続的に語り合える環境には**月1万円の価値がある**

| 段階 | 顧客に与えるもの | 価格目安 | 目的 |
|---|---|---|---|
| フロント | 一度の濃い対話 | 無料〜1,500円 | 不安をなくし、価値を体験させる |
| ミドル | 数日〜数週間の変化 | 3,000〜9,800円 | 対話の効果と運営への信頼を作る |
| バックエンド（Emu本会員） | 継続的な相手・習慣・居場所 | 月額10,000円 | 定着 |

**安いEmuを作るのではない。提供範囲を変える。**
フロント＝一つのテーマ・一度の体験／ミドル＝短期間のプログラム／Emu＝継続する関係と居場所。

### 導線案1：映画・本の感想から入る ★最推奨

Emu の世界観が最も伝わりやすく、初回参加の心理的負担も低い。

**フロント「『面白かった』で終わらせない夜」**（無料〜1,000円 / 60分 / 4〜6人）
指定作品について感想を共有 ／ 正解や知識量を競わない ／ 運営が問いを3つ用意 ／
全員に発言機会を作る ／ 終了後、自分の考えを一文にまとめる

> あの映画について、まだ話し足りない人へ。感想を評価される会ではありません。
> 「なぜ自分は動かされたのか」を、誰かと一緒に見つける夜です。

得る気づき：**感想は、一人で考えるより話したほうが深くなる。**

**ミドル「3作品・対話プログラム」**（4,980〜7,980円 / 3週間）
毎週1作品または1冊 ／ 同じ少人数メンバーで3回対話 ／ 鑑賞・読書前の問い ／ 対話後の振り返り ／
最終回に「自分が大切にしているテーマ」を言語化 ／ Emu本会員とのゲスト対話

得る気づき：**同じ相手と話を重ねると、自分の考え方まで理解してもらえる。**

**移行**：この3週間で終わらせず、毎週新しい作品・知識・人と語り続けたい方へ。

### 導線案2：独学の停滞を解消する

楽しさではなく「学んでも身につかない」という実用的な痛みから入る。

**フロント「15分・知識定着診断」**（無料）
質問例：最近読んだ本の内容を3分で説明できるか ／ 保存した記事を後から見返しているか ／
学んだことを誰かに話しているか ／ 反論や質問を受ける機会があるか ／ インプットが行動に変わっているか

結果分類：積読収集型 ／ 理解したつもり型 ／ 発言恐怖型 ／ 孤独な専門家型 ／ 対話不足型

> あなたに足りないのは、次の教材ではありません。学んだことを自分の言葉にする相手です。

**フロント有料版「30分・読んだ本を説明してみる」**（500〜1,500円）
最近学んだテーマを5分で説明 → 聞き手が質問 → 説明できなかった部分を発見 → 最後に一文で再説明 →
**Before／After を本人に見せる**

**ミドル「7日間・知識を自分の言葉にする合宿」**（3,980〜6,980円）
1日目 テーマを決める／2〜3日目 短い投稿／4日目 他者から質問を受ける／5日目 考え直す／
6日目 少人数対話／7日目 3分間で説明。開始時と終了時の説明を比較。

得る変化：**知ったことが、話せる知識に変わった。**

### 導線案3：「話しすぎる自分」を肯定する

Emu の最もエッジが立つ世界観から集める導線。

**フロント「熱量プロフィール診断」**（無料）
好きな話をすると止まらなくなるか ／ 相手の反応を見て後悔するか ／ 長文投稿を消したことがあるか ／
「考えすぎ」と言われたことがあるか ／ 同じ熱量で返してくれる人がいるか

> あなたは話しすぎるのではありません。話す場所を間違えていただけです。

診断後：同じ熱量タイプの人数を表示 → 一つのテーマを投稿 → 無料体験対話へ招待

**ミドル「考えすぎる人の夜会」**（2,000〜3,500円 / 90分 / 招待制または少人数制）
ルール：結論を急がない ／ 反論ではなく質問から入る ／ 専門用語には説明を添える ／
全員が一つ未完成な考えを持ち寄る ／ 勝敗をつけない ／ 発言を独占しない

体験価値：**初めて、自分の熱量を小さくせずに話せた。**

**上位ミドル「4週間・知的な居場所 体験会員」**（7,980円）
週1回の少人数対話 ／ 興味・熱量診断 ／ 固定メンバーとテーマ別メンバーの両方を体験 ／
1回の再マッチング ／ 対話後の振り返り ／ Emu本会員の一部機能

### 導線案4：ライバル探しから入る

切磋琢磨・継続・成長に強く反応する層向け。

**フロント「知的ライバル相性診断」**（無料）
学びたいテーマ ／ 現在の知識量 ／ 週に使える時間 ／ 優しく応援されたいか厳しく指摘されたいか ／
話す派か書く派か ／ 競争と協力の好み ／ 目標 ／ 継続できなくなる理由

結果：伴走者型 ／ 好敵手型 ／ 教え合い型 ／ 異分野衝突型 ／ 深掘り質問型

**フロント体験版「1回だけの知的スパーリング」**（1,000〜2,000円 / 45〜60分 / 1対1）
共通テーマについて意見を準備 → 互いに説明 → 質問と反論 → 相手のよかった視点を返す →
次回までの学習テーマを決める

**ミドル「21日間・知的ライバル実験」**（6,980〜9,800円）
相性を踏まえて1人とマッチング ／ 週1回・合計3回 ／ 週ごとの課題 ／ 進捗共有 ／
途中で1回だけ再マッチング可 ／ 最終日に相互評価 ／「継続したい／違う相手を探したい」を選択

### 導線案5：話せない人から入る

勉強会で発言できない人、知識量に自信のない人向け。

**フロント「発言しなくても参加できる見学会」**（無料）
最初の20分は聞くだけでよい ／ チャットで質問可能 ／ 発言パス可 ／ 最後に一言だけ感想 ／
**初心者を指名して試すことは禁止**

狙い：**議論は、頭のいい人が完成した意見を発表する場所ではない。**

**ミドル「3回で『質問できる自分』になる練習会」**（3,980〜5,980円）
1. チャットで質問する → 2. 用意した文章を読み上げる → 3. その場で自分の言葉を一言足す

提供価値：正しい質問を作るのではなく**未完成でも話せる経験** ／ 発言後の肯定的なフィードバック ／
少人数・固定メンバー ／ 司会による発言量の調整

### 導線案6：創業者の思想を商品にする

機能ではなく「なぜこの場所が必要なのか」への共感から入る。

> あなたに必要なのは、もう一度きりのイベントではなさそうです。
> 話したいことが生まれるたびに、同じ熱量で返してくれる相手がいる環境を持ちませんか。
> Emu本会員では、毎月最低4回の対話機会と、継続して語れる相手との出会いを提供します。

### 避けるべき商品設計
- フロント商品だけで満足できてしまう
- 無料会員にも無制限の交流を与える
- **月額3,000円程度の常設下位プランを作る**（1万円へ移行せず安い方に居続ける）
- 有料イベントと本会員の違いがない
- フロントからいきなり月額1万円を売り込む
- 無料イベントで参加者を大量に集める
- 自由交流だけを提供し、対話品質を管理しない
- 「成長」「人生が変わる」など測れない成果だけを約束する（§5 参照）
- 割引だけで入会を促す

> ミドル商品は**原則、期間限定・終了日あり**にする。常設の月額下位プランにしない。

### 商品階段の一文要約
> 無料で、自分の孤独に気づく。低価格で、対話の力を体験する。
> 短期プログラムで、自分の変化を確信する。Emuで、語り合える相手のいる人生を始める。

## 21. 課金の決定的瞬間と、ユーザー別シミュレーション

顧客が課金するのは、**「こんな話ができる相手を、もう失いたくない」と感じた直後**。
継続理由はコンテンツ量ではなく人間関係：次に話す約束がある／自分を覚えてくれている人がいる／
話すたびに考えが深まる／自分がコミュニティに必要とされている。

### 共通導線
```
痛みを言語化する投稿
  → 無料診断・質問カード・見学
  → 一度の濃い対話（フロント）
  → 「もっと話したい相手」の発見
  → 3週間の短期プログラム（ミドル）
  → 同じ相手との関係が育つ
  → 終了直前に継続の選択
  → Emu本会員（月額10,000円）
  → 初月オンボーディング
  → 毎週の次回約束・役割・成長記録
```
**無料診断から直接月額1万円へ飛ばさないこと。**

### 1. 映画を観た夜、話せる相手がいない20代（26歳・会社員／最優先ターゲット）
- **認知**: 午前0時、TikTok / Instagram で作品名を検索した先。訴求は「学び」ではなく**今夜残った感情**
  「『面白かった』で終わらせるな。あのラストを、あなたは救いだと思いましたか？」
- **無料**: 作品別「鑑賞後の3つの問い」→ 回答後に他者の解釈を一部だけ開示
  「あなたと違う解釈をした人が、現在7人います」
- **フロント**: 500円・60分・4人の対話会。冒頭で「作品に詳しい人を決める会ではありません」と宣言
- **成約の芽**: 終了直後に「今日、もう一度話したいと思った人はいましたか？」→
  **「相手もあなたと『また話したい』と回答しました」← 最も強いタイミング**
- **ここで月額を売らず**、3週間・4,980円の対話ラボへ
- **転換**: 最終回が盛り上がった直後、解散前。機能ではなく**関係が終わる損失**を明確にする
- **継続理由**: 毎週金曜が「映画を語る夜」になる／次回予定が決まっている／3か月後に
  「自分が何に心を動かされる人か」が見える

### 2. 本を読んでも身につかない30代会社員（34歳）
- **認知**: 「読書 身につかない」検索。「また本を買う前に、前に読んだ本を3分で説明できますか？」
- **無料**: 「学んだつもり診断」→「インプット過多型」→ 60秒録音 →「その考えは、仕事のどの場面で
  使えますか？」に答えられず、理解したつもりだったと気づく
- **フロント**: 1,000円・30分「読んだ本を説明してみる」。最初と最後の説明を比較して見せる
- **ミドル**: 3,980円・7日間「知識を自分の言葉にする合宿」。Before / After を記録
- **転換**: 最終日、成果が本人にも分かった直後
- **売るもの**: 居場所ではなく**学びが使える状態になること**
- **継続の可視化**: 「今月、あなたが自分の言葉にした知識：4件」

### 3. 「話が長い」と言われる20代女性（23歳・月1万円に心理的抵抗あり）
- **認知**: 「あなたは面倒くさいんじゃない。話す場所を間違えていただけだ。」
- **無料**: 「熱量タイプ診断」→「深掘り暴走型」＋「同じタイプが今週32人参加しています」（所属可能性）
- **フロント**: 「考えすぎる人の夜会」初回無料。聞くだけ・チャット参加可
- **決定的体験**: 参加者から「それ、もっと聞きたい」と言われる一言
- **アプローチ**: 直後に営業文を出さず、本人の言葉を返す
  「あなたが話している間に、3人が『もっと聞きたい』と反応しました」
- **ミドル**: 7,980円・4週間「知的な居場所」体験会員。自分のテーマを一度主催できる
- **転換**: 初めて主催し、感想を受け取った直後。「参加者としてではなく、Emuの一員として」
- **価格対策**: 割引ではなく**役割との交換**（学生枠／ファシリテーター活動による会費補助／招待クレジット）

### 4. 勉強会で一言も話せない人（29歳・エンジニア）
- **認知**: 「知識がないからではありません。完成した言葉でなければ話してはいけないと
  思っているからです。」
- **フロント**: 発言しなくても参加できる見学会（無料）。最初の20分は聞くだけ可、チャット質問可、
  司会が匿名で読み上げ、**初心者を指名して試すことは禁止**
- **ミドル**: 4,980円・3回「質問できる自分」になる練習会（匿名チャット → 用意した文章の音読 →
  その場で自分の言葉を一言足す）
- **転換**: 3回目に本人の質問から10分以上議論が続いた直後
- **提案の言い方**: 「あなたは議論についていけない人ではありません。議論を深める問いを持っている人です」
- **位置づけ**: Emu は「話すのが得意な人の場所」ではなく**未完成な考えを出しても置き去りにされない場所**

### 5. 切磋琢磨できる相手を求める起業家・専門職（38歳・価格抵抗小・時間の無駄を最も恐れる）
- **認知**: LinkedIn / 紹介。「『すごいですね』しか言わない人は、ライバルではない。」
- **フロント**: 2,000円・45分の1対1知的スパーリング。事前に仮説・反論してほしい点・
  欲しい専門性・**厳しさの程度**を登録
- **ミドル**: 9,800円・21日間「知的ライバル実験」。3回＋再マッチング1回
- **転換**: 2〜3回目で**本人の仮説が実際に変わった瞬間**。「今日の対話で仮説から変更した点を記録してください」
- **提案の言い方**: 「情報への料金ではなく、あなたに忖度せず思考を止めない相手と話し続ける環境への料金です」
- **価値指標**: 「月4回」ではなく**今月、意思決定を一つ改善できたか**

### 6. SNSの議論に疲れた40代（44歳・管理職・新規コミュニティに警戒）
- **認知**: 「意見が違う人を、敵にしない夜。」
- **フロント**: 1,000円・見学可能な少人数対話会。**申込前に**進行ルール・司会者プロフィール・人数・
  録画しないこと・通報/退出ルール・個人情報の扱い・当日のテーマを開示（信頼構築）
- **ミドル**: 5,980円・3回「違う意見と話す対話ラボ」。同意しなくてよい／要約してから反論／
  人格批判禁止／結論を出さなくてよい
- **転換**: 「意見は変わらなかったが、相手がなぜそう考えるかは分かった」と本人が答えた瞬間

### 7. Talkin から流入する国際交流好き（21歳・無料に慣れており価格抵抗が強い）
- **認知**: Talkin 内の体験会・招待コード。「『どこに住んでるの？』の次へ。」
- **フロント**: 多言語テーマ対話会（無料〜500円）
- **ミドル**: 4,980円・3週間「国際対話ラボ」。**言語能力で評価しない**
- **転換**: 外国の参加者から「あなたの国では、なぜそう考えるの？」と問い返され、
  初めて自分の価値観を説明した直後
- **注意**: この層は価格との相性が弱い。学生・無料サービス利用者をそのまま本会員候補にせず、
  社会人／留学経験者／国際業務従事者／語学へ継続投資している人に絞る

## 22. 月額1万円をいつ・どう提案するか

### 提案してよいタイミング（いずれかの直後）
- 「またこの人と話したい」と回答した／**相手からも選ばれた**
- 終了予定時刻を越えて話した
- 自分の考えが変わった／初めて発言できた／自分の質問が議論を深めた
- 次のテーマを自分から提案した／「次回はいつですか」と聞いた
- 短期プログラムの終了を惜しんだ

### 提案してはいけないとき
体験前／対話で満足できなかった直後／参加回数が少ない人への強い販売。**逆効果になる。**

### 言い方
避ける: 「Emuにはこんなにたくさん機能があります。今なら月額1万円です。」

推奨:
> 今日のような対話を、偶然の一度で終わらせず、毎週持てるようにするのがEmuです。
> あなたの興味と熱量に合う相手との対話を、月4回以上提供します。月額は10,000円です。
> 30日間参加しても「また話したい相手」に一人も出会えなければ、初月料金は全額返金します。

**価格を出す前に、本人が体験した価値を具体的に振り返る。**
「最初は発言できるか不安だと話していました。今日はあなたの質問から議論が12分続きました。
この変化を続けたいですか？」

## 23. 入会後30日と、使い続ける仕組み

**入会後に放置すると初月で解約される。**

| 期限 | やること |
|---|---|
| 24時間以内 | ウェルカム／興味・熱量・話し方・希望時間の登録／初回対話の候補提示／今月得たいものを一つ決める／創業者から短い動画 |
| 3日以内 | 最初の対話を確定／相手のテーマだけ先に共有（緊張を減らす）／対話ルール案内 |
| 7日以内 | 初回対話を実施／直後に「もう一度話したいか」確認／合わなければ即再マッチング／良ければその場で次回確定 |
| 14日以内 | 2回目の対話／自分のテーマを一つ投稿／他会員から反応／**小さな役割を持つ** |
| 30日以内 | 最低3〜4回の対話／対話記録の可視化／「考えが変わった瞬間」の振り返り／**翌月の相手・テーマ・日程を先に確定** |

### 継続の仕組み
1. **次の約束を先に作る** — 毎回の終了時に、次のテーマと日時をその場で決める。
   解約しにくくするためではなく「利用しようと思っていたのに忘れた」を防ぐため
2. **固定関係と新しい出会いを両立** — 月4回なら 継続relationship 2回／新しい相手 1回／テーマ別グループ 1回。
   固定だけでは閉鎖的、新規だけでは関係が深まらない
3. **役割を渡す** — 参加者 → 質問者 → テーマ提案者 → 進行補助 → 主催者 → 新規会員の迎え役。
   「お金を払って参加する場所」から「自分が必要とされる場所」へ
4. **変化を記録する** — 対話回数／話した時間／出会ったテーマ／もう一度話したい相手／自分が投げた問い／
   考えが変わった瞬間／受け取った言葉／誰かに影響を与えた記録。
   **滞在時間や連続ログイン日数ではなく、対話による変化を可視化する**
5. **休眠前に介入** — 兆候: 7日間ログインなし／2回連続キャンセル／評価が低い／投稿に反応がない／
   次回予定がない／毎回違う相手だけで関係が育っていない。
   連絡は催促ではなく原因の特定（日時／相手／テーマのどれか一つだけ聞く）→
   日時変更・再マッチング・テキスト参加・少人数化・テーマ変更を提案

### 休会プランは設けない（2026-08-15 オーナー確定）
検討段階では「解約を防ぐより休会を用意する」案があったが、**採用しない**。
プランを増やさず、解約と再入会だけで扱う。

## 24. 最初に実行する一本の導線と指標

全ユーザーを同時に狙うとメッセージもマッチングも薄くなる。**最初はこの一本に絞る。**

**対象**: 映画を観た後、深く語りたいのに相手がいない20〜30代
**集客**: Instagram / TikTok / 映画タイトル検索 / 映画コミュニティ

1. 作品別の短い問いを投稿
2. 無料の3問診断
3. 500円の4人対話会
4. 終了直後に相互「また話したい」確認
5. 4,980円の3週間対話ラボ
6. 最終回終了直後に Emu本会員を提案
7. 30日間「語り合える一人」保証
8. **入会時に翌月の対話予定を確定**

### 計測する指標（売上だけを見ない）
投稿→診断開始率／診断→体験申込率／体験申込→出席率／初回対話後の「また話したい」率／
**相互マッチ率**／体験→ラボ購入率／ラボ完了率／ラボ→本会員転換率／初月に3回以上対話した割合／
2か月目継続率／3か月目継続率／継続相手が一人以上いる割合

> **最重要指標は、月額1万円への成約率ではなく「相互にまた話したいが成立した割合」。**
> ここが低ければ、営業を強くしても継続しない。

### 最終的に売っているもの
アプリでもイベントでもない。
> **話したいことが生まれたとき、次に話したい相手がすでにいる生活。**
