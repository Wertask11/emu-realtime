# Emu ブランド・事業戦略ブリーフ

最終更新: 2026-08-17 / 情報源: オーナー（合同会社型DAO SchoolPark 代表）からの直接共有

Emu の大型アップデート完了を受けて、宣伝・広告・集客・収益フェーズへ移行する。
本ドキュメントは全部門エージェントの共通前提とする。**確定事項と推奨案（未確定）を必ず区別すること。**

正式タグライン ★確定（2026-08-17）：

> **「あなたの熱に、ついてこられる場所。」**

一文要約：

> Emu は、映画・本・学び・知識について深く語りたいのに、周囲との温度差から自分の情熱を隠してきた人が、
> 同じ熱量を持つ相手と出会い、対話を通じて知識を使える言葉へ変える、月額1万円の会員制ディスカッションサービス。

### ⚠️ 2026-08-17 時点で全部門が守るべき最重要の3点

1. **対話の相手は創業者本人のみ。** 会員同士のマッチングは実装しておらず、当面その予定もない。
   宣伝・営業・LP で「会員同士のマッチング」「熱量の合う会員と出会える」「多様な会員コミュニティ」
   といった表現を使うことを**禁止する**（景表法上の優良誤認にあたる）。
   使ってよいのは「創業者自身が、あなたの興味に合わせて対話の機会をお届けします」。
2. **月額は3プラン（light 500 / plus 3,000 / pro 10,000）で継続する。**
   「語り合える一人」保証と返金の対象は **Emu pro のみ**。
   「返金保証つき」とだけ書くことを**禁止する**（有利誤認）。必ず「Emu pro（月額10,000円）には」を添える。
3. **「初月無料」「初月0円」「まずは無料でお試し」は使用禁止。**
   規約・特商法で「初月無料ではない。入会時に初月料金を決済する」と明記済み。
   保証を無料体験のように言い換えると、表示と実際の取引条件の食い違いになる。

## 1. 原点（創業者の没頭と怒り）

**没頭・偏愛**
- 知識を交換すること / 人と一緒に学ぶこと
- 映画を観た後に感想や考えを言い合うこと / 本について深く話し合うこと
- 意見をぶつけ合い、考えが深まる瞬間
- 切磋琢磨できる相手との関係

**怒り・苛立ち**
- Emu がまだ不人気であること
- 議論の楽しさに周囲がついてこないこと / 深く語り合える人がいないこと
- ライバルや切磋琢磨できる相手がいないこと
- 好奇心や情熱を出すと「面倒な人」として扱われる空気
- 学びが一人きりのインプットで終わってしまうこと

**届けたい価値**
ディスカッションの楽しさ / 個人間の知識共有 / 考えを自分の言葉にする体験 /
熱量の合う相手との出会い / 一人では到達できない学び / 好奇心を小さくしなくてよい居場所

## 2. 本質的な顧客課題

表面的には「知識共有の場所がない」「話し相手がいない」だが、**深層の痛みは次の一点**。

> 知りたい、考えたい、語りたいという自分の熱を、周囲に合わせて小さくし続ける苦しさ。

共通する感情：
- 人数ではなく、思考の深さや熱量が合わない孤独
- 考えすぎる自分への羞恥 / 好きなことを話しすぎた後の自己嫌悪
- 「意識が高い」「面倒くさい」と思われる恐怖 / 発言前に自分を止める自己検閲
- 未完成な意見を出せない不安 / 学んでいるのに変化していない焦り
- 同じ熱量を返してくれる相手への渇望
- 対話を通じて、自分の考えの価値を確かめたい気持ち

**ポジショニングの核**：Emu は知識共有アプリではなく、**考えすぎる自分を、もう隠さなくていい場所**。

## 3. 宣言文

**現在の宣言文（オーナー提示・要改善と評価済み）**

> 私は、もっと自由に学びたいのに周りが許してくれないで悩む情熱（学びたいという意思）をもつ人間のための、
> 知識の共有を個人間で行えるようにするアプリ「Emu」をつくった起業家です。

セグメントが広すぎるという評価。理由：
- 「自由に学びたい人」の範囲が広い
- 「周りが許してくれない」の状況が曖昧
- 「知識共有」が機能説明にとどまっている
- 顧客が「自分のことだ」と即断しにくい

**最有力の代替案（推奨・未確定）**

> 私は、映画や本に心を揺さぶられた夜、語りたいことが溢れているのに、話せる相手がいない人のために、
> 「面白かった」の先を語り合えるアプリ「Emu」をつくった起業家です。

## 4. 顧客セグメント ★確定（7つ・2026-08-17）

最初の突破口として **1 が最有力**。

各セグメントの正式なターゲット文（宣言文の細分化。広告・営業でそのまま使ってよい）：

1. 「私は、映画や本に心を揺さぶられた夜、語りたいことが溢れているのに、話せる相手がいない人のために、『面白かった』の先を語り合えるアプリ『Emu』をつくった起業家です。」
2. 「私は、学んだことを話すたびに『意識高い』『難しい話はやめよう』と煙たがられてきた人のために、知りたい気持ちを遠慮せずぶつけ合えるアプリ『Emu』をつくった起業家です。」
3. 「私は、考えを深めたいのに、SNSでは短い共感か言い争いにしかならないと感じる人のために、勝ち負けのない議論ができるアプリ『Emu』をつくった起業家です。」
4. 「私は、本や動画で学び続けても、誰とも話さないため知識が身につかず、独学に限界を感じる社会人のために、対話によって学びを自分の言葉にできるアプリ『Emu』をつくった起業家です。」
5. 「私は、勉強会に参加しても、詳しい人に気後れして質問も意見も言えずに帰ってしまう人のために、知識量に関係なく対話へ参加できるアプリ『Emu』をつくった起業家です。」
6. 「私は、本気で学び続けたいのに、刺激し合える仲間がおらず、情熱がひとりで冷めていく人のために、知識をぶつけ合えるライバルと出会うアプリ『Emu』をつくった起業家です。」
7. 「私は、好きなことを深く話すほど『熱すぎる』『話が長い』と引かれてしまう人のために、情熱を小さくしなくていいアプリ『Emu』をつくった起業家です。」

各セグメントの内面（言い当てに使う）：

1. **映画や本について深く語る相手がいない人**（最有力）
   「面白かった」で会話が終わる / 作品で動いた感情を一緒に解釈してほしい /
   観賞直後の熱が冷める前に話したい / 作品を通して自分自身を理解したい
2. **知的好奇心を煙たがられる人**
   「意識高い」「また難しいことを考えている」「その話、長い」/ ひけらかしと誤解される / 興味のないふりをしている
3. **SNSでは深い話ができない人**
   長文を投稿前に消す / 強く断言しないと注目されない / 反論より雑に理解されるのが怖い / 未完成の考えを一緒に育てたい
4. **独学に限界を感じる社会人**
   保存するだけで終わる / 一週間後には説明できない / 収集が自己満足 / 初歩的な理解を見せるのが恥ずかしい
5. **勉強会で発言できない人**
   初歩的な質問だと思われるのが怖い / 文章を作る間に話題が変わる / 一言も話せない / 初心者を安全に開示したい
6. **切磋琢磨できる仲間がいない人**
   応援だけでは足りない / 「その考えは甘い」と言ってほしい / 手の届くライバルが欲しい / 競い合って可能性を確かめたい
7. **好きなことを話しすぎて引かれる人**
   相手の表情を見て後から反省する / 好きなことを話すときだけ自分らしい / 同じ熱量を返してほしい /
   話しすぎではなく場所を間違えている

## 5. サービス価値と表現上の制約 ★重要

**オーナー提示の価値**
毎日 Emu を利用して知識共有を達成する / 人生における自分らしさを取り戻す / 知ること・学ぶことの楽しさ /
学びに対する物理的・金銭的な悩みを減らす / できなかったことができるようになる /
押し付けられた勉強ではない本当の学び / 使える知識 / 学ぶ楽しさ

**広告表現の禁止・注意（全部門が遵守）**

以下のような断定は、合理的な裏付けがない限り景品表示法上のリスクがあるため使わない。
- 「悩みが生涯なくなる」
- 「必ず使える知識が手に入る」
- 「人生が必ず変わる」

**Emu が保証しやすいのは人生の結果ではなく、提供する機会そのもの**：
対話機会の提供 / マッチング回数 / 参加できる場 / 話せる機会 / 振り返りの提供 / 再マッチング

## 6. 価格 ★確定（2026-08-17 更新）

**月額サブスクリプションを3プランで提供する。すべて Stripe で実装済み・稼働中。**

### ★★ 3プランが、そのまま商品階段である（2026-08-17 オーナー確定）

**これが最重要の前提。読み違えないこと。**

| 段 | プラン | 価格 | 「語り合える一人」保証 | 提供内容 |
|---|---|---|---|---|
| **フロントエンド商品** | **Emu light** | 月額 500円 | なし | **未確定（設計中）** |
| **ミドルエンド商品** | **Emu plus** | 月額 3,000円 | なし | **未確定（設計中）** |
| **バックエンド商品** | **Emu pro** | 月額 10,000円 | **あり** | 30日間で最低4回の対話機会。相手は創業者本人 |

- フロント／ミドル／バックエンドは、**3プランとは別に用意する単発商品ではない。**
  **light がフロント商品そのもの、plus がミドル商品そのもの**である。
- したがって、フロント・ミドルも**月額サブスクリプション**として成立させる。
  単発イベントとして設計してはならない。
- 収益の柱は Emu pro。light と plus は、**pro へ上がるための階段**として設計する。

> **旧版の誤り（2026-08-17 訂正済み）**：以前の §20 は
> 「フロント商品＝『面白かった』で終わらせない夜（単発500円）」
> 「ミドル商品＝3週間・知的対話ラボ（単発4,980円）」と、
> light / plus とは**別物の単発商品**として書いていた。これは誤りである。
> それらの企画内容は、**light / plus の中身を考えるときの素材**として扱う。

**light / plus の提供内容はまだ決まっていない。** 価格だけが先行している状態で、
「500円で何が得られるか」が曖昧なままだと解約率を押し上げる。商品開発部の最優先課題とする。

### 設計で外してはならない条件

1. **pro の劣化版にしない。** 安い方に居続けて pro へ上がらないと、階段が機能しない。
   light / plus は「pro に上がりたくなる設計」でなければならない。
2. **1対1の対話は pro だけの価値として温存する。** light / plus に1対1を付けると即座に破綻する（§31）。
3. **グループなら人数を捌ける。** 1対1は45分で1人だが、4人のグループ対話なら60分で4人。
   時間あたり4倍以上になる。light / plus をグループで組めば、
   §31 の上限（同時15人前後）は 1対1 の pro にだけかかる制約になる。
4. **light（500円）は粗利478円/月。** 運用工数は価格に比例しないため、
   人手の介在を前提にした設計にすると即赤字になる。

pro の価格帯では単なる SNS・投稿アプリでは成立せず、**会員制の濃い対話サービス**として設計する必要がある。

必要な要素：本人確認 / 月4回以上の対話機会 / 運営による進行設計 / 安全管理 / 通報・ブロック /
対話後の評価（「また話したい」の相互選択）/ 対話記録・振り返り

> **注意：マッチングは含まない。** 上表の「相手は創業者本人」が確定仕様である。
> 旧版のこの節にあった「関心や熱量を踏まえたマッチング」「再マッチング」は、
> 将来構想であって現行仕様ではない。運営キャパシティの上限は §31 を参照。

### 実装上の既知の欠落（経理部・技術開発部より）

- **light / plus から pro へのアップグレード導線が存在しない。** 現在は一度解約して入り直すしかなく、
  商品階段の設計と噛み合っていない。Stripe 側は `subscription.update` で対応可能。
- **返金は「売上ゼロ」ではなく約430円の純損失になる。** Stripe は返金しても決済手数料を返さない。

## 7. リスクリバーサル ★確定（2026-08-12）

> **確定した内容（実装済み・`docs/emu-membership-setup.md`）**
>
> 「語り合える一人」保証を採用。30日間で最低4回の対話機会を提供し、3回以上参加しても
> 「また話したい」と思える相手に一人も出会えなければ、**初月料金10,000円を全額返金**する。
> 判定は本人の評価と利用記録。申請期間は入会31日目から7日間、一人につき1回限り。
> 希望者には返金前に創業者が直接話を聞き、無料で対話を1回設定する（返金の条件ではない）。
>
> **追加5,000円の補償は取りやめた。返金は初月料金の全額のみ。**
> 対話の相手は**創業者本人**が務めるため、マッチングのアルゴリズムは作らない。
>
> 以下は決定に至るまでの検討記録。**下の「最低4回の対話保証（1回2,500円換算）」と
> 「追加5,000円補償」は採用していない。** 顧客向けの文面は
> `frontend/public/guarantee.html` と利用規約 第5条の3 が正。

### 検討記録（以下は不採用案を含む）

**前提：初月無料ではない。初月10,000円を先に決済し、条件を満たしても価値を届けられなければ返金する設計。**

基本の流れ：
1. 入会時に 10,000 円を決済
2. 30日間利用
3. 保証条件を満たしても価値ある相手に出会えなければ返金
4. 継続する場合は翌月も 10,000 円
5. 次回決済前の解約で翌月請求なし

### 「語り合える一人」保証【採用】
30日以内に「また話したい」と思える相手と出会えなければ、初月料金 10,000 円を全額返金。

条件案：初回入会者 / プロフィール完成 / 興味・関心テーマ登録 / 対話可能日時登録 /
30日間で3〜4回以上の対話に参加 / 対話後の評価に回答 / 無断欠席や重大な規約違反がない / 所定期間内に返金申請

判定基準：本人が「もう一度話したい」と評価した相手が一人もいない場合。
感情の証明は要求せず、**本人の評価と利用記録**で判断する。

### 最低4回の対話保証【不採用】
月4回の対話機会を提供できなかった場合、未提供回数分を返金（1回 2,500 円換算）。
3回なら 2,500 円 / 2回なら 5,000 円 / 0回なら 10,000 円全額。

### Emu 側の不履行に対する追加補償【不採用】
Emu 側の責任で対話機会を提供できなかった場合、全額返金に加えて 5,000 円を補償。
**「満足しなかった」という主観ではなく、Emu 側の提供不履行に限定する。**

### 創業者直結保証【採用・希望制】
30日間参加しても居場所が見つからなければ創業者が直接話を聞く。再マッチングしても解決しなければ全額返金。
初期フェーズでは顧客調査と改善を兼ねるため有効。

### 採用した最終構成 ★確定
> 30日間で最低4回の対話機会を提供します。
> 「また話したい」と思える相手に一人も出会えなければ、初月料金 10,000 円を全額返金します。
> 希望される方には、返金前に創業者が直接お話を伺い、相手を選び直して、もう一度無料で対話を設定します。

（検討段階にあった「Emu 側の不履行に対する追加5,000円補償」は**採用しない**と決定した。）

### メールログイン
パスワードではなく**マジックリンク**を推奨。
流れ：メール入力 → 一回限りのURL送信 → ユーザーがURLを開く → トークン検証 → セッション発行

必要：認証基盤 / メール配信サービス / 独自ドメイン / SPF・DKIM・DMARC / HTTPS / トークン生成・検証 /
再送制限 / 迷惑メール・バウンス管理 / メール変更・復旧手続き

セキュリティ：有効期限10〜15分 / 一回利用後は即時失効 / トークンを平文保存しない /

### 電話番号ログイン
**SMS によるワンタイムコード**。

必要：国際SMS事業者 / 国番号対応 / E.164形式への正規化 / OTP生成・検証 / 配信結果管理 /
再送・試行回数制限 / SMS不正送信対策 / 電話番号変更 / 番号再割当てへの対応 / SMSが届かない場合の代替ログイン

保存例：表示 `090-1234-5678` / 保存 `+819012345678`

セキュリティ：OTP有効期限5分程度 / 入力試行最大5回程度 / 正解後に即時失効 / OTPを平文保存しない /
再送は30〜60秒待たせる / 電話番号・IP・端末・国ごとの送信制限 / 番号変更時に現在の方法で再認証 /
変更後に旧番号・メールへ通知 / 重要操作の一時制限 / **SMSを唯一の復旧方法にしない**

リスク：SIMスワップ / 電話番号の解約・再割当て / SMS盗聴 / 海外で届かない / SMS pumping /
VoIP・使い捨て番号 / 複数人で共有される番号

推奨形：**SMS OTP ＋ メールまたは Google／LINE による復旧**

## 12. 認証データの管理

一人のユーザーに複数ログイン手段を紐付ける。

**基本原則**
- メールや電話番号そのものを内部ユーザーIDにしない
- ランダムな `user_id` を主キーにする
- 認証情報とプロフィール情報を分ける
- 電話番号・メールを暗号化し、検索用に別の照合ハッシュを持つ
- OTP やマジックリンクの平文を保存しない
- **MetaMask の秘密鍵やシードフレーズを絶対に保存しない**

**想定テーブル**
- `users` — 内部ID / 表示名 / ステータス / 言語 / 国 / 年齢区分 / 作成・更新・削除日時
- `auth_identities` — ユーザーID / 認証プロバイダー / プロバイダー側ユーザーID / 暗号化メール /
  メール照合用ハッシュ / 暗号化電話番号 / 電話番号照合用ハッシュ / 確認日時 / 最終利用日時
- `auth_challenges` — 送信先のハッシュ / 認証目的 / トークンのハッシュ / 有効期限 / 試行回数 / 使用済み日時
- `sessions` — ユーザーID / リフレッシュトークンのハッシュ / 端末情報 / IP情報 / 有効期限 / 失効日時
- 監査ログ — ログイン成功・失敗 / OTP送信 / メール送信 / 連絡先変更 / 外部アカウント連携・解除 /
  決済情報変更 / アカウント削除 / 管理者による操作

**監査ログにも完全なメールアドレス、電話番号、OTP、アクセストークンは記録しない。**

### 重複アカウント対策
想定される問題：Googleで登録後にLINEで新規登録 / 電話番号でさらに別アカウント / 月額課金の重複 /
投稿やフォローが複数アカウントへ分散

必要な機能：ログイン後の「ログイン方法を追加」/ アカウント統合 / 統合前の再認証 /
**課金中アカウント同士は自動統合しない** / 投稿・メッセージ・フォローの統合ルール / 統合・解除の通知 /
サポート担当の承認記録 / 不正統合を防ぐ待機期間

## 20. 商品階段（フロント／ミドル／バックエンド）

月額1万円は「便利そうだから登録する」価格ではない。いきなり売るのではなく、顧客に次の順番で
気づいてもらう必要がある。

1. 自分は学べないのではなく、**語る相手がいない**
2. 対話すると、作品や知識の**理解が深まる**
3. **誰と話すか**で、対話の質が大きく変わる
4. 継続的に語り合える環境には**月1万円の価値がある**

| 段階 | 顧客に与えるもの | 価格目安 | 目的 |
|---|---|---|---|
| フロント | 一度の濃い対話 | 無料〜1,500円 | 不安をなくし、価値を体験させる |
| ミドル | 数日〜数週間の変化 | 3,000〜9,800円 | 対話の効果と運営への信頼を作る |
| バックエンド（Emu本会員） | 継続的な相手・習慣・居場所 | 月額10,000円 | 定着 |

**安いEmuを作るのではない。提供範囲を変える。**
フロント＝一つのテーマ・一度の体験／ミドル＝短期間のプログラム／Emu＝継続する関係と居場所。

### 導線案1：映画・本の感想から入る ★最推奨

Emu の世界観が最も伝わりやすく、初回参加の心理的負担も低い。

**フロント「『面白かった』で終わらせない夜」**（無料〜1,000円 / 60分 / 4〜6人）
指定作品について感想を共有 ／ 正解や知識量を競わない ／ 運営が問いを3つ用意 ／
全員に発言機会を作る ／ 終了後、自分の考えを一文にまとめる

> あの映画について、まだ話し足りない人へ。感想を評価される会ではありません。
> 「なぜ自分は動かされたのか」を、誰かと一緒に見つける夜です。

得る気づき：**感想は、一人で考えるより話したほうが深くなる。**

**ミドル「3作品・対話プログラム」**（4,980〜7,980円 / 3週間）
毎週1作品または1冊 ／ 同じ少人数メンバーで3回対話 ／ 鑑賞・読書前の問い ／ 対話後の振り返り ／
最終回に「自分が大切にしているテーマ」を言語化 ／ Emu本会員とのゲスト対話

得る気づき：**同じ相手と話を重ねると、自分の考え方まで理解してもらえる。**

**移行**：この3週間で終わらせず、毎週新しい作品・知識・人と語り続けたい方へ。

### 導線案2：独学の停滞を解消する

楽しさではなく「学んでも身につかない」という実用的な痛みから入る。

**フロント「15分・知識定着診断」**（無料）
質問例：最近読んだ本の内容を3分で説明できるか ／ 保存した記事を後から見返しているか ／
学んだことを誰かに話しているか ／ 反論や質問を受ける機会があるか ／ インプットが行動に変わっているか

結果分類：積読収集型 ／ 理解したつもり型 ／ 発言恐怖型 ／ 孤独な専門家型 ／ 対話不足型

> あなたに足りないのは、次の教材ではありません。学んだことを自分の言葉にする相手です。

## 21. 課金の決定的瞬間と、ユーザー別シミュレーション

顧客が課金するのは、**「こんな話ができる相手を、もう失いたくない」と感じた直後**。
継続理由はコンテンツ量ではなく人間関係：次に話す約束がある／自分を覚えてくれている人がいる／
話すたびに考えが深まる／自分がコミュニティに必要とされている。

### 共通導線
```
痛みを言語化する投稿
  → 無料診断・質問カード・見学
  → 一度の濃い対話（フロント）
  → 「もっと話したい相手」の発見
  → 3週間の短期プログラム（ミドル）
  → 同じ相手との関係が育つ
  → 終了直前に継続の選択
  → Emu本会員（月額10,000円）
  → 初月オンボーディング
  → 毎週の次回約束・役割・成長記録
```
**無料診断から直接月額1万円へ飛ばさないこと。**

## 23. 入会後30日と、使い続ける仕組み

**入会後に放置すると初月で解約される。**

| 期限 | やること |
|---|---|
| 24時間以内 | ウェルカム／興味・熱量・話し方・希望時間の登録／初回対話の候補提示／今月得たいものを一つ決める／創業者から短い動画 |
| 3日以内 | 最初の対話を確定／相手のテーマだけ先に共有（緊張を減らす）／対話ルール案内 |
| 7日以内 | 初回対話を実施／直後に「もう一度話したいか」確認／合わなければ即再マッチング／良ければその場で次回確定 |
| 14日以内 | 2回目の対話／自分のテーマを一つ投稿／他会員から反応／**小さな役割を持つ** |
| 30日以内 | 最低3〜4回の対話／対話記録の可視化／「考えが変わった瞬間」の振り返り／**翌月の相手・テーマ・日程を先に確定** |

### 継続の仕組み
1. **次の約束を先に作る** — 毎回の終了時に、次のテーマと日時をその場で決める。
   解約しにくくするためではなく「利用しようと思っていたのに忘れた」を防ぐため
2. **固定関係と新しい出会いを両立** — 月4回なら 継続relationship 2回／新しい相手 1回／テーマ別グループ 1回。
   固定だけでは閉鎖的、新規だけでは関係が深まらない
3. **役割を渡す** — 参加者 → 質問者 → テーマ提案者 → 進行補助 → 主催者 → 新規会員の迎え役。
   「お金を払って参加する場所」から「自分が必要とされる場所」へ
4. **変化を記録する** — 対話回数／話した時間／出会ったテーマ／もう一度話したい相手／自分が投げた問い／
   考えが変わった瞬間／受け取った言葉／誰かに影響を与えた記録。
   **滞在時間や連続ログイン日数ではなく、対話による変化を可視化する**
5. **休眠前に介入** — 兆候: 7日間ログインなし／2回連続キャンセル／評価が低い／投稿に反応がない／
   次回予定がない／毎回違う相手だけで関係が育っていない。
   連絡は催促ではなく原因の特定（日時／相手／テーマのどれか一つだけ聞く）→
   日時変更・再マッチング・テキスト参加・少人数化・テーマ変更を提案

### 休会プランは設けない（2026-08-15 オーナー確定）
検討段階では「解約を防ぐより休会を用意する」案があったが、**採用しない**。
プランを増やさず、解約と再入会だけで扱う。

## 30-2. 100個の悩みから営業トークをつくる方法

「100人に受ける一つのトーク」ではなく、**「一人を射抜く100個のトーク」**を考える。

### 基本の6段階

1. **言い当て** — 「最近、〇〇で悩んでいませんか？」
   本人が実際に経験する場面や心の声を具体的に言葉にする。
2. **共感** — 創業者自身に本当に同じ経験がある場合だけ、その経験を話す。
   同じ経験がない場合は「Emuをつくる過程で、同じような声を聞いてきました」など、事実に沿って表現する。
3. **問題の再設定** — すぐに本人の意志、性格、努力不足を原因にしない。
   環境、相手、機会、方法が合っていない可能性を示す。ただし、単一の原因だと断定しない。
4. **望む変化** — Emu が管理できる具体的な体験だけを提示する。
   （好きなことを最後まで話せる / 一度以上、対話へ参加できる / 違う視点を聞ける /
   「また話したい相手」を探せる / 学んだことを自分の言葉で説明する機会を持てる）
5. **オファー** — 顧客の温度に応じて提案する。
   （無料コンテンツ / Emu light / Emu plus / Emu pro）
6. **意思確認** — 煽らず、本人へ選択権を返す。
   （「まず一度、同じ熱量で話せる時間を体験してみませんか。」
   　「今の自分に必要だと感じたら、参加してください。」）

### 営業姿勢

> **「目線は対等に、理解は深く、説明は丁寧に、約束は具体的に。」**

創業者を先生・主治医・救世主として演出しない。顧客を患者として扱わない。

### 各悩みを分析する出力形式

100個の悩みを一件ずつ扱う場合、以下を出力する。

1. 元の悩み
2. 想定人物
3. 具体的な状況
4. 本人が言えない本音
5. Emu との関連性
6. 直接解決・間接軽減・対象外の分類
7. 言い当て
8. 共感
9. 問題の再設定
10. 望む変化
11. 最適なオファー
12. 押しつけない意思確認
13. 広告コピー
14. 使用禁止表現
15. 専門家への案内が必要か
