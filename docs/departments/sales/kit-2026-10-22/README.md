## 3. 使い方のきまり（資料とオーナーの言葉から）
- **話す順番（Camellia）**：Camellia → 今日の自分 → Place → このお店がどう紹介されるか。60秒デモは Today → Check → 今日のあなた → Discover → Place。
- 30秒トークは 1 の⑥ にある。技術・運営体制の話は聞かれたときだけ。
- **使わない言い方（Camellia）**：送客の保証、提携済みと受け取られる表現、効果・効能をうたう表現。医療・診断・治療の代わりと言わない。
- 連絡先：資料の Camellia 側は「各種SNSにて」。**メールアドレスはオーナーが渡すときに口頭で伝える。** 各ブランドの案内チラシに SNS の QR があり、そこも説明する（2026-10-22 オーナー）。
- 8・12 にある「確認できませんでした」（削除機能・議論の保存期間・イベントの個人情報）は、**オーナーが対面で説明する**（2026-10-22 オーナー）。部署は文面の書き直しを求めない。
- 「契約だけが成功ではない」。各訪問で小さなYES（資料を受け取った・QRで見た・次回連絡OK など）と NEXT ACTION を 14 に書く。
