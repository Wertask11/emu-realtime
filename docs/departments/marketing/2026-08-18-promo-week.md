**フロント商品「『面白かった』で終わらせない夜」もミドル商品も未実装です。**
決済フローも定員管理もありません。そのため各投稿の CTA は購入リンクではなく
**DM／リンクからの参加表明**に統一しています（日程はオーナーが手動で調整する前提）。

架空の残数・煽りは使っていません（§31 の運営キャパ上限に基づく）。

## X 投稿原稿（7本・そのまま投稿可）

### 1日目（8/18）旧Emuと新Emuの違い

```
Emuは、大きく変わりました。

これまでのEmuは、知識を共有し、もっと自由に学べる場所を目指していました。その思想は今も変わっていません。

でも、知識を共有できるだけでは足りませんでした。

同じ熱量で話せる相手がいなければ、知識は一人の中で止まってしまう。

だから、新しいEmuは「情報」ではなく「人との出会い」を中心につくり直しました。

映画や本について、「面白かった」の先まで話せる。
学んだことを、遠慮せず交換できる。
知識量に関係なく、考えを言葉にできる。

あなたの熱に、ついてこられる場所。— Emu
```

**スレッド2投目**

```
旧Emu→新Emu、何が変わったか。

旧：知識を共有するアプリ
新：熱量で語れる相手と出会い、対話を続けられる場所

旧：情報が主役
新：人と対話が主役

旧：知りたいことを知れる
新：話したいとき、話したい相手がいる

旧：一度の知識共有で終わる
新：「また話したい」が続く関係になる
```

### 2日目（8/19）旧Emuが不人気だった事実と学び

```
正直に話します。

旧Emuは、不人気でした。

知識を共有できる場所を作れば、人は自然に集まると思っていました。
甘かった。

投稿に反応はついても、深い対話は生まれなかった。
一度話せても、その関係は続かなかった。
だから、人はまた同じ孤独に戻っていった。

「知識の置き場所」を作っても、孤独は解決しなかった。

これが、旧Emuから学んだこと。
次は、なぜつくり直したかを話します。
```

### 3日目（8/20）なぜつくり直したか

```
なぜ、Emuをつくり直したか。

決められたことをこなし、周囲に合わせ、毎日の小さな問題につつかれながら、気づけば人生が終わっていく。
そんな一生にはしたくなかった。

もっと知りたい。もっと考えたい。もっと面白い人と出会いたい。
映画を見たあとに「面白かった」で終わらせたくない。
本を読んで生まれた問いを、一人で消したくない。

でも、その熱についてこられる人や場所が、周りになかった。

だから、情熱を小さくして周りに合わせるのではなく、
その情熱についてこられる場所そのものをつくることにした。

それが、Emu。

あなたの熱に、ついてこられる場所。
```

### 4日目（8/21）セグメント①：映画・本

```
午前0時。観終わった映画の感想を、誰にも言えないまま画面を閉じたことはありませんか。

「面白かった」で終わらせるには、心が動きすぎた夜がある。

あのラストを、あなたは救いだと思いましたか。それとも、突き放されたと感じましたか。

Emuは、その続きを話せる場所です。
正解も知識量も競いません。「なぜ自分は動かされたのか」を、誰かと一緒に見つける時間です。

あなたの熱に、ついてこられる場所。— Emu
（対話の相手は創業者本人です。参加希望はプロフィールのリンクから）
```

## Instagram 原稿（1日目・最終日）

### 1日目 — カルーセル用キャプション（§28 の正式告知文を無改変で使用）

```
Emuは、大きく変わりました。

これまでのEmuは、個人と個人が知識を共有し、もっと自由に学べる場所を目指していました。
その思想は、今も変わっていません。

でも、知識を共有できるだけでは足りませんでした。

どれだけ話したいことがあっても、同じ熱量で話せる相手がいなければ、知識は一人の中で止まってしまう。

一度だけ話せても、その関係が続かなければ、また同じ孤独に戻ってしまう。

だから、新しいEmuでは、情報ではなく「人との出会い」を中心に据えました。

映画や本について、「面白かった」の先まで話せる。
学んだことについて、遠慮せず意見を交換できる。
知識量に関係なく、質問や考えを言葉にできる。
そして、「この人とまた話したい」と思える関係をつくっていく。

Emuは、知識を共有するだけのアプリから、
あなたの情熱についてこられる相手と出会い、対話を続けられる場所へ変わりました。

変わったのは、見た目や機能だけではありません。
Emuが届ける価値そのものを、もう一度つくり直しました。

新しいEmu。
「あなたの熱に、ついてこられる場所。」

#Emu #知的対話 #考えすぎる人へ #学び直し #熱量
```

## 禁止表現チェック（§29）

全10本（X7本＋IG/TikTok/YouTube 各1本）で以下の不使用を確認済み。

- 「初月無料 / 初月0円 / まずは無料でお試し」
- 「返金保証つき」（プラン名なし）
- 「熱量の合う会員と自動でマッチング / 多様な会員コミュニティ」
- 「必ず / 生涯 / 人生が変わる / 絶対 / 100%」
- 虚偽の実数（「〇〇人参加」「残りわずか」）
- 「学校より学べて公園より楽しくて会社より稼げる」

4日目・最終日には「対話の相手は創業者本人」を明記し、マッチング誤認を防止している。
