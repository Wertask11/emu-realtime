# プラン確認・申し込み導線の修正

2026-10-16。既存の「SchoolParkパスポート→価値プロフィール→プランをアップグレードする」でAUTH_REQUIREDとなる報告への修正。

## 変更

- SchoolPark・Emu共通ヘッダーに「プラン・お支払い」を追加。スマホでは「プラン」と短く表示。既存入口も維持。
- 会員画面のiframeを一度だけ目的のURLで開き、同一オリジンの親アプリのFirebase Authを共有。別のAuth初期化と二重ナビゲーションを避ける。
- AuthorizationはHeadersオブジェクトでも保持。401時は同じ本人のトークンを一度だけ更新し、ログイン中の本人が変わった応答は採用しない。
- 認証失敗時は日本語の案内と再読み込み。自動復元がない旧ウォレットセッションは、利用者が入口を押したときだけ既存の署名ログイン復帰を利用する。LINE/Googleにウォレットログインを要求しない。
- 必要なプラン情報を先に表示。プロフィール・対話の取得失敗でプラン画面全体を隠さない。proの保証に必要な対話情報は別途取得し、保証の対象外の人には保証申請欄を表示しない。
- 現在の権利→プランの目的・月額→年齢確認→カード決済、の順に整理。全機能の比較は開いて読む形。契約のない無料利用は0円と表示。
- 未ログインで選んだプランは、短時間の遷移先だけをsessionStorageへ保持し、ログイン後に再開。トークンや本文は保存しない。
- 遅れて戻るログイン既定遷移が、利用者の開いた会員画面を上書きしない。

価格・利用枠・既存公式パスの約束・EMUER・Camelliaは変更しない。Firestore Rulesの追加反映は不要。
