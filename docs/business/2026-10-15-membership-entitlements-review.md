**太字の保存・下書き・研究枠は2026年10月15日にFounder合意。保存・研究の縮小は11月1日0時JSTから適用する。** 特にLabの保存・研究は現在全プラン1,000件なので、無料・lightへ新上限を入れる場合は事前告知・既存データ保護・適用時点を決める必要がある。「この表のとおり現在動作する」とはまだ表示しない。

公開済み投稿の編集は新規投稿数に再加算しない。公開投稿から研究を作るだけで元投稿を書き換えたり公開範囲を変えたりしない。Quest用の投稿の既存例外は保持する。

### 枠の数え方

- 投稿・募集・回答・議論作成：毎月1日0:00日本時間に更新する案。契約の支払日とは別と明記する。日割り課金・更新日・解約はStripeの契約周期として別に表示。
- 保存知識は保存解除すると枠が戻る。下書きは公開などで同時保有枠から外れる。研究ノートは保管しても記録と履歴が残るため、保管分を含むと表示する。
- 原稿・ノート・ブックマークを無断削除しない。枠超過の既存データも本人は読めて修正・書き出しできる。新規作成を止める適用日は、告知と移行方針を決めてから設定する。
- 月途中のアップグレードは、その月の既使用数を保ったまま上限が増える。ログイン方法やプラン変更を使って使用数をリセットできない。ダウングレードは既存データを消さない。
- 「保管」と「公開取り下げ」と「完全削除」は意味を分ける。課金が切れたから記録を人質にする画面にしない。

### AIの販売上の扱い

AIはプラン価格の差の主役にせず、同意済みの公開経験知から発見する共通機能とする。各Passport最大分析3回/日、全体10回/日、埋め込み全体60回/日など現在の制限を維持。残り枠・停止・無料枠到達時は実行前に説明し、課金へ自動移行しない。AIが使えなくても、人が比較・編集・保存する研究は継続できる。

無料の元知識参照も閲覧範囲を超えて取得できないことをAPIで検証する。外部AIへの送信可否と会員段階は別条件で、plusやproでも作者の同意なしの投稿・非公開知識は送らない。

## 3. SchoolParkの権利は、購読プランだけで買い切らせない

| 機能・権利 | 推奨する区分 |
|---|---|
| SchoolParkへの一般入場・公開閲覧 | 一般公開期間の現在の条件を維持。月額契約必須とはしない |
| 一般Questを受ける・報告する | 本人性と各Questの条件。月額の高さで完走・信用を買えない |
| Guildの関与・特殊の投票 | 現行の公式パスまたは所定の信用などの条件を維持。plus/pro購入だけで条件を飛ばさない |
| 公園のボード・挑戦を出す | 現行light以上または運営の条件を維持 |
| Cityを見る・買う | 公開期間・ログイン・本人性・商品条件に従う。商品代金・送料・実費は別 |
| Questの予算・EMUER・信用スコア | 実際の活動と既存の確認・分配ルール。課金額に比例する自動報酬は追加しない |
| 管理画面・分類統合・第三者確認 | 運営だけ。proや公式パス購入で管理者になれない |

「どの機能も全部有料にする」案ではなく、SchoolParkの活動で価値を感じ、Emuで継続して学び・記録・対話する人に購読してもらう構成。

## 4. 公式パスでできること

### 既存の第一弾〜第三弾：販売時の買い切り権を維持

- Emu plusの対象機能を、約束した対象サービス・保有条件に基づいて追加月額なしで使う。新しい機能表を採用する場合も、既存購入者の約束を下げない。
- Passportに認証・保有がつながり、対象のGuild関与など既存の公式パス資格を使える。
- 自動的には付かないもの：proの対話・返金保証、運営権限、無制限AI、現物商品・外部実費、新しいEMUER配布、未発行NFTの自動発行。
- すでにplus権を持つ人に、同じplusの重複課金を勧めない。proへ上がる場合の支払額・既存パス権との関係は、実装前に明示する。現行価格を維持するならproは月10,000円で、黙って「差額7,000円」等の新価格を作らない。
- 系列・出品価格・残数・当時の販売条件はFounderの実記録と突合する。住所や名称だけで旧/新シリーズを推測して権利を変更しない。

### 最初の5人のFounding Emuer：通常パスと混同しない

Quest #000で定義された既存の個別約束を引き継ぐ。対象者と権利は本人確認済みの運営台帳で管理する。一般のパス条件で上書きしない。対象となるサービスの利用料と、現物・送料・外部実費等は区別する。今回Camellia等の他サービスを変更する許可としては扱わない。

### 将来の新シリーズ案：plus年パス

**候補：30,000円でplusを12か月。未決定・未販売。** 月3,000円×12＝36,000円より6,000円低い年払い相当。自動更新しない一括購入案で、期限前に利用者が更新を選ぶ。現在のシリーズ完売・既存の約束・Founderの販売方針を確認してから判断する。

- 含む：plusの機能、期間中の対象パス資格、保持していることを示す表示。購入時に開始/終了日と対象サービスを明示する。
- 含まない：永久plus、pro対話、無制限AI、商品の無料購入、配当・価格上昇・換金の保証。
- 期間終了後も本人の記録は保持し、共通の閲覧・編集を守る。パスの記念的な表示と有料機能の有効期限は別に扱う。
- 技術上は、旧パスの恒久的な保有判定と、新パスの期限付き利用資格を別レコードで管理する。現在の `holdsOfficialPass→plus` へ新シリーズをそのまま足すと永久plusになるため、そのまま販売しない。

年パス1枚で入金30,000円になっても、毎月30,000円のMRRが増えるわけではない。12か月の利用権として月2,500円相当の提供義務が残る。単発売上を当月のキャッシュフローには含め、継続売上の10万円達成とは区別する。

## 5. 決定後の実装・購入導線の完成条件

1. 機能名・対象・上限・期間・例外をサーバーの1仕様から取得し、比較画面・購入前説明・上限時メッセージへ同じ値を表示。Rulesで必要な制限も一致させる。
2. 契約・付与・パスの正本とPassportの紐付けを確認し、同じ本人のLINE/Google/ウォレットで同じ権利になる。契約の所有権を移したり、外部支払いを作り直したりはしない。
3. 「あなたの現在の権利・残り枠・上がると増える枠」を表示。すでに権利を持つ人へ重複課金しない。
4. 購入前に税込価格・更新・解約・保証対象・AIの制限を表示。Checkout開始だけで成功扱いにせず、Webhookの確定後に権利を付ける。
5. 決済後は元の投稿・検索・研究へ戻す。上限時にも入力を保持する。パスは円/カードと暗号資産を実ボタンで選べるようにする。
6. 既存契約とパスへの影響をdry-runで一覧化し、個別の約束と事前通知を反映。データ初期化・既存記録の削除・推測による統合はしない。
7. 無料/3プラン/旧パス/新パス/創設期付与/期限切れ/複数資格/複数ログインをテスト。本人認証・返金・解約・アップグレード・二重Webhook・権限違反を確認し、Founderの本番購入確認を経る。
