# City 3D showroom

Cityの「3Dの街へ入る」から、WebGLの店舗に入り、移動・見回し・商品選択ができます。床をクリック／タップすると衝突判定を使って自然に歩き、ドラッグ／スワイプで見回せます。PCではWASD／矢印キーも補助操作として利用できます。商品はクリック／タップ、または中央に合わせてEキーで選べます。Passportへの訪問記録は既存のCityチェックインを使います。

今回の店舗はオリジナルの展示用モデルです。実店舗の写真・寸法からの再現ではありません。年内のリアル店舗連携1〜2拠点という目標に合わせ、連携候補枠を2つ設けています。

## 公開範囲

- 通常入口：SchoolPark → 08 City → 3Dの街へ入る。既存のログイン・入場判定・Passport IDを利用します。
- 操作プレビュー：`/schoolpark/city-showroom.html`。公開された展示データのみ使用し、ログイン・記録・注文・決済は行いません。
- 初期商品はすべて展示品で、価格は参考表示です。購入は無効です。
- 3Dは入口を押したときに読み込みます。終了・ログアウト時に描画とイベントを解放します。描画中断時には新しいcanvasで再試行できます。

## 実店舗の決済接続

`backend/city-shops.json`をレビューして更新します。販売を有効にするには、店舗を`live`にし、販売者名・提供方法・返品条件・問い合わせ先、許可する決済ホスト、商品の`checkout.enabled`・HTTPS URL・支払い方法を設定する必要があります。購入者のリクエストから価格や決済URLを受け入れません。

商品選択後、サーバーで再確認し、販売条件と移動先を表示して、利用者が店舗の決済ページへ進みます。対応方法の表示はJPY／JPYC／EMUERですが、実際の決済手段は接続先店舗での実装・確認が必要です。City自体にネイティブのJPYC／EMUER決済、カート、在庫同期、配送管理、決済Webhookはありません。リンクを開いても購入完了扱いにせず、残高・星・購入履歴を書き換えません。

実店舗の販売開始には、店舗の掲載許可、写真・寸法、商品データ、正式な決済先と販売条件が必要です。現在の共通モデルは商品の先頭4件を3D配置し、全商品を一覧から選べます。

## ビルド・反映

Three.js 0.186.1とesbuild 0.28.2を固定しています。`tools/city-build`で`npm ci && npm run build`を実行すると、自己配信する約544KBのエンジン、MITライセンス、購入不可のプレビュー用カタログを生成します。通常のフロント配信時に追加ビルドは不要です。

Vercelは`frontend/public`、Renderは既存のバックエンドを反映します。新しい店舗APIの反映も必要です。Firestore Rules・DB移行・追加環境変数は不要です。

バックエンドの反映確認はCity APIの`X-SchoolPark-City-Release: 3d-shops-v1`ヘッダーを使用できます。未認証リクエストには従来どおり401を返し、店舗データやPassport情報を公開しません。

## 検証

`cd backend && node --test`で認証・Passport・City・決済先検証と既存バックエンドの回帰を確認します。ブラウザ検証は`node --test --test-concurrency=1 tools/guild-tests/city.test.cjs tools/guild-tests/city-3d.test.cjs`です。検証用DB・認証を使用し、実注文・実送金は行いません。

幅375／390／412／768／1440px、移動・商品選択・訪問記録・終了・ログアウト・描画中断からの再開を対象にしています。実機スマートフォンのGPU性能と実店舗での決済・配送は別途確認が必要です。

## 時間帯で変わる外の世界（2026-11-10）

店の外（空・光・広場）が、起動（ロゴ）画面と同じ時間帯で変わります。店内・商品・歩き方・決済・Passportはこれまでどおりです。

| 時間帯 | 時刻 | 街 |
|---|---|---|
| 朝 | 4:00–9:59 | 朝焼けの広場。噴水、旗、風船、朝市、鳥 |
| 昼 | 10:00–15:59 | 雲の上に浮かぶ街。浮島、クリスタル、気球、虹 |
| 夜 | 16:00–3:59 | 夜祭り。やぐら、提灯、屋台、花火、星空 |

- 時間帯は `city-time.js` が決めます。起動画面が決めた `window.SP_SPLASH_MODE` があればそれに合わせ、無ければ端末の時刻で同じ区切りを使います。
- 確かめるとき：`/schoolpark/city-showroom.html?cityTime=morning|day|night`。アプリ本体は `/?splash=…` でロゴ画面ごと切り替わります。
- 外の世界は `city-atmosphere.js`。形もテクスチャもその場で作り、外部の画像は使いません。動くもの・光るものはクリックの当たり判定から外してあり、商品や床のタップを邪魔しません。読み込みに失敗しても、店はこれまでどおり開きます。
- 歩ける範囲を店の南の広場まで広げました（x −16〜12、z −8〜24）。右下の「朝の広場へ／空の広場へ／夜祭りへ」で広場の前に移動できます。
- 屋台・朝市は飾りです。販売や既存のイベントページへのリンクはありません。
- 動きを減らす設定（prefers-reduced-motion）の端末では、花火・風船・雲などの動きを止めます。
- テスト：`CITY_TIME=morning|day|night` を付けて `city-3d.test.cjs` を走らせると、その時間帯で確かめられます。
