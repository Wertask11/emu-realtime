# 参加したくなる理由を伝える追加UX改善

2026-10-19。PR #217を本番へ反映した後の追加フィードバックに対応。最新main `283dc3e5cb5bdfd2848233f63a12fe14b9466571` から `fix/participation-value` を作成した。今回の追加分は本番未反映。

「参加のハードルを越えるには動機が必要」という声に対し、参加しない安心に加えて、知識を使う体験と自分に残せるものを案内する。既存の課題・知識・資料を先に見せ、個別内容を一般的な説明で埋めない。

| 参加前に知りたいこと | 表示する内容・根拠 |
|---|---|
| 何を体験できるか | ギルドの既存テーマ・議題・クエストから活動を選ぶ。クエスト固有の「やること／提出するもの」はそのまま表示 |
| どんな知識を使うか | 既存の元知識・現場資料、自分の経験を課題の条件に照らす。未登録の推薦・教材を生成しない |
| どんな人・視点と関わるか | 同じ分野の議題、実際の参加者一覧、存在する報告から他の試し方や気づきを知る。指導者や相談相手の割当・個別交流は約束しない |
| 何を得られるか | 自分の実践・つまずき・気づきの報告と、一文にした知恵カード。新しい報酬・資格・仕事紹介等を特典にしない |
| 参加後に何をするか | ギルドの参加希望は意思の登録で次の活動は別途選択。クエストは取り組み・3種類の報告・知恵カード・運営確認。締切・報酬等の既存条件はそのまま |

## 変更範囲

- `frontend/public/schoolpark/dao.html`：ギルド・クエスト一覧の短い紹介文、詳細の「できること・残せるもの」案内。原点#000には報告・完走の追加案内を表示しない。
- `frontend/public/service-header.css`：既存色・文字サイズの説明パネル。PCは3列、タブレット・スマホは1列。
- `tools/tour-tests/reizo-tour.test.cjs`：表示専用の追加範囲を明示し、残りのファイル全体の比較を維持。
- `tools/knowledge-lab-tests/participation-ux.py`：同じ7幅の操作フローで追加案内の表示も確認。前回の証拠を上書きせず出力先を選べるようにした。
- この報告書と証拠画像・実行結果。

SchoolParkの全scriptタグ内容は公開済みmainと完全一致。index.html、Firestore Rules・インデックス、ギルド・クエスト定義、認証・Passport、報酬バックエンド、チュートリアルの定義・進捗、冷蔵庫くんの会話・保存は変更なし。新しい書き込み・推薦・強制参加やポップアップは追加しない。
