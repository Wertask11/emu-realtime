## 調査と現行仕様

- 最新mainを取得。開始時のHEAD/mainは `f52dc21cbe20c7e09ea21bf7496a0f4e5487cd8a`。開始時に未コミット変更なし。専用ブランチは `fix/participation-ux`。
- 本番をPC 1440px・スマホ390pxの実Chromiumで確認。ロゴからログイン方法の選択まで操作した。ログインせずに切替UIを操作することはできず、ギルド・クエストの本番ログイン後画面／参加前後は未確認。新規登録や本人ログインは実施していない。通信はGET/HEAD/OPTIONSに限定し、参加・報酬・分析イベント等の書き込みリクエストを遮断した。
- 本番のログイン後と偽ってはいない。参加操作の検証には専用の `demo-emu-knowledge-lab-ux19` とテストアカウントだけを使用した。
- ギルドの「参加したい」は `sp_guild_members/{guildId}/joins/{addr}` へ `name/at` を保存。「応援する」は `supports` へ同じ形を保存。もう一度押すと本人の記録を削除する。担当・締切の割当、クエスト受注、投票、報酬、通知送信の処理は含まれない。登録した名前は公開読み取り対象。
- クエストの「受ける」は `sp_quests/{questId}/commits/{addr}` へ `name/tookAt` を保存する。閲覧・資料の展開・一覧の絞り込みは参加を作成しない。参加すると報告を書けるようになる。未完走なら辞退確認を経て削除でき、完走済みは既存のUI処理で辞退を防いでいる。出した報告は編集・削除できない。
- 完走の承認は既存の `backend/quest-completion.js` が扱う。3種類の報告、知恵カード、本人性などの確認があり、受注だけで報酬は確定しない。個別条件・予算・期限・難易度・既存記録は変更しない。
- 所要時間の専用フィールドは確認できなかった。推定時間を捏造せず「要確認（本文・提出物・手順を確認）」と表示する。
- チュートリアルは既存IDと保存状態を維持。冷蔵庫くんには、現在の5つのギルドと一致しない「一般ギルド／特殊ギルド」の説明が残っていた。一般／特殊は議題の投票資格であり、この説明を現行コードに合わせた。

## UXの問題と実装

1. 以前は小さい矢印やスマホのメニュー内から切り替える必要があり、Emuを発見しにくかった。共通ヘッダーに現在の名前＋「切替」＋大きい矢印を常設。PCの既存サイドバーも矢印・補助文字・44pxの押しどころを改善した。両方とも既存の切替・アクセス判定を再利用する。
2. 切替はネイティブbutton、現在地表示、フォーカス表示、Escape・Tab・キーボード操作に対応。SchoolParkの再描画中にフォーカスを失うケースも、切替ボタンに限定して保持するよう修正。
3. ギルドのカードに「活動を見る」を表示し、カードを開いても登録されないと説明。参加希望・応援と、クエスト受注・投票を区別。登録／取り消しの既存処理には変更を加えていない。
4. クエスト一覧は「内容を見る（参加しません）」に統一し、一覧からの即受注を外した。詳細に既存の受注ボタンを残し、その前に、名前の公開・締切・予算・報告・運営確認・辞退と記録の扱いを表示。既存の仕事／報酬／税の説明は削除せず展開式で残した。
5. 運営が既存の `stage` に「入門」と設定したものだけを絞る機能を追加。未設定を初心者向けと推定しない。該当なしの案内と絞り込み解除を用意した。
6. Emu「知識を探す」に、読むだけの利用を維持したままSchoolParkの活動を知る入口を追加。SchoolParkホームにも活動／クエストをまず閲覧する入口を置いた。強制参加・投稿・新しい推薦エンジンは追加していない。
7. チュートリアルの対象ID・進捗・自動再開の条件を変更せず、説明文だけを新しい入口に合わせた。冷蔵庫くんのFAQも実際の参加・完走・辞退仕様に合わせた。会話エンジンと会話保存は変更しない。
