# 分類の複数選択をクリック・タップに統一

従来はHTMLのselect multipleを使っており、PCで離れた分類を選ぶにはCtrl／Commandなどが必要だった。「複数可」という表示だけでは操作が分からず、普通に次の分類をクリックすると前の選択が解除されていた。

分類欄をすべてラベル付きチェックボックスへ置き換えた。分野・業種・職業・経験・目的・形式・ジャンル・難易度・対象者・経験時期、既存job分類の表示、検索と除外条件、書き手プロフィール、知識募集、運営分類付与で同じ部品を使う。選択件数と名前を常に欄の下に表示する。再クリックでその項目だけを解除できる。検索の条件解除とフォームリセット、URLからの複数選択の復元にも対応する。

送信する分類IDの配列、保存形式、公開範囲、所有権判定は変更しない。Firestore Rules・インデックス・API・認証・EMUER・Camellia・root index.htmlの変更はない。既存投稿の分類を自動で変更しない。

- 1件だけの解除、Spaceキー、実タッチ入力、選択件数の表示、検索の複数分類、共有URLからの復元、除外条件と検索リセット、非公開書き手プロフィールと知識募集への配列保存、フォームリセットの表示を確認。
- 375／390／412／768／1024／1366pxでモーダルとページの横はみ出しなし。選択行44px以上、ページ例外0。実際のPC／タッチ画像も確認。
- 証拠は `/workspace/outputs/knowledge-lab-facet-checkboxes/results.json` と `LOCAL-*.png`。
- 旧投稿の一覧→編集→同じIDへ保存→再ログイン、他人の一覧から除外、古い一覧応答の無視も、更新したチェックボックス用テスト操作で再確認。
