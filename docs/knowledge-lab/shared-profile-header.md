# SchoolPark・Emuの共通プロフィール

2026-10-16。上部の操作をプロフィールと冷蔵庫くんの2つに整理。両方から既存のEmuプロフィールメニューを開く。SchoolParkパスポートはメニュー内の入口から利用する。

プラン・お支払い、設定はプロフィール内に置く。従来のSchoolPark設定（招待・ID・キャッシュ削除・ログアウト）を共通設定として引き継ぎ、従来のEmuの名前／プロフィール画像の選択も同じ画面に統合した。

本人の保存済みheaderIdentityModeを利用し、両サービスの上部ボタンへ同じ名前／画像を反映。画像が無い・読み込めない場合は名前へ戻る。設定保存は既存の本人確認付きAPIのみで行い、Headers形式のAuthorizationも維持。保存に失敗した場合は以前の値へ戻す。新しいRules・料金変更・データ移行は不要。Camelliaは変更しない。

アカウントメニューを非表示になるサービス本体の外へ移し、押したプロフィールボタンの位置に表示する。既存ログイン処理が持つDOM参照は同じ要素のまま維持。SchoolParkの再描画後も保存済みの表示を反映する。
