# Lab導線・共通ヘッダーの改善（2026-10-15）

## 変更した体験

- Labには「← Emuに戻る」、投稿ガイドには「← Knowledge Labに戻る」「← Emuに戻る」を常設。ログイン済みの親画面の戻る処理を利用し、ロゴを押す操作に依存しない。
- ガイドを別タブで開き、元の投稿フォーム・研究の入力を残す。ガイド内からLabへ戻る場合も正規のログイン入口へつなぐ。既存シェル内で開かれたガイドの戻る処理も扱う。
- 「知識募集」は「経験者に質問する」と表示し、既存のEmu「知識を探す」と同じ募集・回答・報酬制度であることを説明。投稿済み知識の図書館検索へ戻るボタンも追加。DBの複製はない。
- 図書館・投稿・プロフィール・質問の多数の任意分類を開閉式にする。編集時・共有URLで選択済みの分類がある場合は展開し、選択を見落としにくくする。複数選択と各軸は維持。
- キーワード検索時はGeminiへの送信確認を隠し、意味検索を選んだときに表示。AI送信の必須確認自体は維持。
- Labの初回案内を4ステップに更新。研究・保存先・質問募集・書き手プロフィールも現在の画面の「使い方案内」から再生できる。研究でAIが自動入力するタイミングと、手動比較との違いも説明。自動保存・自動AI実行はしない。他のサービスの案内履歴は変更しない。
- SchoolPark・Emuのヘッダーに同じ順序のプロフィール・冷蔵庫くん・設定を置く。操作ボタンは44px角、ヘッダーはスマホ68px・それ以上88px。同じCSSを共有する。既存の認証・Passport・冷蔵庫くん・各サービス設定の処理を利用する。
- Emuの既存の名前/画像の選択をPCでも反映。長い名前はボタン内で省略し、アカウントメニューで確認できる。ログイン方法とIDは変えない。
