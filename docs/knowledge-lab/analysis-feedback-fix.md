# AI分析の拒否理由と、手動比較・自動入力の区別

Founderの本番操作で `/ai/analyze` の403、その後409が報告された。HTTPステータスだけではサーバーのエラーコードは確定しない。公開読み取りで確認できた選択投稿「失敗から学ぶ」にはAI利用同意がなく、これはサーバーが403 `AI_SOURCE_CONSENT_REQUIRED` で送信を拒否する条件に該当する。409については選択分野を元投稿がカバーしない場合などがあり、エラー本文は未受領。

## 変更

- 選択中の各元投稿へAI利用同意の有無、非公開の場合の対象外表示、内容・同意を確認する導線を追加。
- 分析ボタン直下に進捗・成功・失敗理由・安全なエラーコードを表示。失敗した場合は③に今回の結果を入れていないことを明示し、人が書いた内容を保持する。
- 投稿者が既存編集フォームで明示同意を保存すると、研究で選択中の投稿情報も更新。拒否後も保存済みの同意を再取得する。自動で同意を付けない。
- 分析・再分析を同時実行しない。分析後の別の状態取得だけが失敗しても、完了した結果・自動入力を失敗扱いにしない。
- 「選んだ知識を比較する（手動）」を元投稿・分類を並べる機能と説明し、AI分析ボタンを主ボタンにする。③はAI成功時に入力され、手書きも可能と説明する。
- バックエンドの同意・公開範囲・認証・費用上限・Rulesを変更しない。401/403を回避しない。本番利用者データやAI設定を書き換えない。

- 未同意の投稿を含む分析が403で拒否され、模擬生成呼び出し0。未同意投稿のタイトルと理由を画面に表示。
- 手動比較の成功では③を自動入力しない。分析失敗時は空欄も手入力済み内容も保持。
- 投稿者がUIから同意を明示保存すると選択欄の状態へ即反映。
- 模擬分析成功1回で出典を表示し、③へ入力→自分用研究へ永続保存。
- 処理中表示・重複クリック防止・状態取得の故障注入でも成功表示を保持・新規ノートで過去のメッセージを消去。
