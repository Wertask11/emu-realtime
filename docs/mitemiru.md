# みてみる（SchoolPark内の交換所）

運営が置いた商品を、EMUER・JPYC・円で手に入れる場所。支払いが確かめられると引換コードが出て、会場で運営に見せて受け取る。

- 画面: `frontend/public/schoolpark/east-shopping.html`（Emuの「みてみる」から開く）
- サーバー: `backend/mitemiru.js`（`/api/mitemiru`）、テスト `backend/mitemiru.test.js`・`backend/mitemiru-shops.test.js`
- 画面の試験: `tools/shop-tests/east-shopping.test.cjs`

## 画面の作り

もとからある School Park Mall のデザインをそのまま使う。
ヒーロー・花びら・時計・カウントダウン・ショップ一覧・新着のカルーセル・
セール・カート・紙吹雪・ショップの小窓は、2026-10-04 に一度作り直して
しまったぶんを元へ戻した。CSS と HTML の骨組みは、作り直す前と
1バイトも違わない（`tools/shop-tests/east-shopping.test.cjs` が見ている）。

繋いだのは、もともと `[MIGRATE]` の印が付いていた中身だけ。

| もと | いま |
|---|---|
| `const SHOPS = []`（空の決め打ち） | `/shops` と `/products` から読む |
| `?owner=1` で運営 | `/me` の `isOwner` |
| 購入が `console.log` だけ | 払い方を選ぶ → 注文 → 引換コード |
| オーナーパネルが見せかけ | ショップ・商品を本当に登録、当日の引換もここ |

カートだけは端末の中（`localStorage`）に置いたまま。買うときにサーバーへ
注文を立てるので、売り買いそのものには関わらない。

### ショップと商品

画面は「ショップを選ぶ → 中の商品を見る」という並び。商品だけでは
その階層が作れないので、`mitemiru_shops` を置いて商品が `shopId` で
ぶら下がる。ショップに入れない商品も置ける（売り場では「SchoolPark」に
まとまって出る）。ショップは消さずに `ended` にする（商品と注文の記録を残すため）。

カートの中身は、全部で使える払い方だけを出す。1つでも使えない商品が
混ざっていると、まとめては払えない（そのときは分けて買ってもらう）。
1つの注文は1点ぶん。2点なら注文も引換コードも2つになる。

## 支払いの方法

| 方法 | 確かめ方 | 回数枠 |
|---|---|---|
| EMUER（未変換） | 未受取の報酬を `spent` にする。多いぶんはおつりの報酬にする | Light 月1・Plus 週1・Pro 無制限、無料は不可 |
| EMUER（ウォレット） | `EMUERv2.exchange` の注文記録を鎖で確かめる | 同上 |
| JPYC | 受取先への送金を鎖で確かめる（2承認）。同じ送金は二度使えない | なし |
| カード | Stripe Checkout（単発）。Webhook か確認ボタンで支払い済みを確かめる | なし |
| 会場で現金 | 運営が引換コードで探して「現金を受け取って渡した」 | なし |

回数枠は v2 の「みてみるの交換」枠（`emuer_v2_access_usage` の `exchange`）と共通。支払いが成功したときだけ消費し、運営都合の返金で取り消す。

未変換の報酬は、受け取りの署名を出すと `authorizedUntilMs` が付き、その期限まではみてみるで選ばない（鎖の上でも受け取れて二重に使えるのを防ぐ）。`spent` の報酬には署名を出さない。

## 本番で必要なこと

1. **Firestore Rules を反映する**（`mitemiru_*` をブラウザから書けないようにした）。反映前に公開すると、誰でも注文を支払い済みにできてしまう。
2. Render の環境変数
   - `EMUER_V2_AUTHORIZER_PRIVATE_KEY`（既存）: ウォレットのEMUER払いの署名に使う
   - `STRIPE_SECRET_KEY`・`STRIPE_WEBHOOK_SECRET`（既存）: カード払い。Webhook は月額会員と同じ `/api/billing/webhook`、イベントは `checkout.session.completed`
   - `MITEMIRU_JPYC_RECEIVER`（任意）: JPYCの受取先。未設定ならトレジャリー `0x1C15…CFE4`
3. ウォレットのEMUER払いの返金・受け渡し済みの記録（`refundExchange`・`markExchangeFulfilled`）は、`REFUND_ROLE` を持つ運営ウォレットで「運営」タブから行う。受け渡し済みにしないと、その額は返金用の取り置きとしてトレジャリーに拘束されたまま。

## 運営の流れ（イベント当日）

1. みてみるを開き、「Owner」タブへ（運営のアカウントでログインしていると出る）
2. **New Shop** でショップを作る（任意。作らなくても商品は置ける）
3. **New Item** で商品を出す（値段は EMUER・JPYC・円の3つ。入れたものだけが払い方として出る。
   在庫を空にすると無制限。「会場で現金を受け取る」に印を付けると、当日の現金払いができる）
4. 来場者がカートに入れて「購入する」→ 払い方を選ぶ → **引換コード**が出る
5. **引換（当日）** にコードを入れて「コードで探す」→「渡した」
   （現金なら「現金を受け取って渡した」の1回で、受け取りとお渡しが済む）

お渡し待ちの注文は、同じ段に一覧で出るので、コードを聞かなくても処理できる。

## City公式ショップ（schoolpark-official）

EMUER だけで交換する店。商品ごとに「渡し方」（`fulfillmentMode`）を決める。

| 渡し方 | 中身 | 買った人の取り消し |
|---|---|---|
| `digital` | 交換するとその場でダウンロード | できない |
| `ship` | 自宅へ配送（注文のときに住所を入れる） | 締切まで |
| `ship_or_pickup` | 配送か、イベント会場での受け取りを選ぶ | 締切まで |
| `pickup` | 会場で受け取る（優先席・限定枠など） | できない |
| `online` | オンライン参加（企画会議など）。日時は運営から連絡 | できない |

- **締切**（`orderDeadlineMs`）：受注生産の品に付ける。過ぎると交換できない（`ORDER_CLOSED`）。月末に締めて、翌月の中ごろに発送する。
- **取り消し**：未変換の EMUER で払った注文はその場で全額戻す。ウォレットで払った注文は「申し出」になり、運営が「運営」タブで `refundExchange` してから返金する。
- **配送先**：`mitemiru_shipping/{注文ID}` に注文とは別に置く（ブラウザからは読めない）。電話番号は運営の配送一覧にだけ出る。取り消し・期限切れ・返金で消し、発送から1年たつと `purgeShipping` で消す（プライバシーポリシー第7条）。
- **デジタルの品**：ファイルを `backend/private-assets/` に置き、`catalog.json` に `{ "<ID>": { "file": "...", "downloadName": "..." } }` を足す。商品の `digitalAssetId` にその ID を入れる。買った本人だけが `/orders/:id/digital` で受け取れる。
- **数字**：`mitemiru_metrics/{日付}` に「ショップを開いた・商品を見た」の回数だけを数える（個人の情報は入れない）。交換の件数は注文から数える。City の「イベント運営」に出る。
- 規約は第5条の6。特定商取引法の表記にも「City 公式ショップでの商品交換について」の欄がある。
- **11品の登録**：中身は `backend/official-shop-products.json`（名前・説明・EMUER・在庫・締切・画像）。City の「イベント運営」で「11品を下書きで登録」を押すと下書きで入る。何度押しても同じで、販売中・交換済みの品には触らない。確かめてから1品ずつ「販売を始める」。
- **画像**：`frontend/public/schoolpark/shop/official/`（Vercel）。URL は `PUBLIC_SITE_ORIGIN`（無ければ `https://schoolpark-emu.vercel.app`）から組む。
- **1人1つまで**（`onePerPerson`）：投票権・優先席・企画会議。`mitemiru_claims/{商品とuidのハッシュ}` で持っているかを示し、取消・期限切れ・返金で消す。
- **選ぶもの**（`choices`）：Guild バッジの5種。注文の `choice` に残り、交換履歴と配送の一覧に出る。
- **商品ページの画像**（`gallery`）：デザイン案など6枚まで。

## 気をつけること

- **EMUER で払うには、Emu Light 以上と、連携したウォレットが要る。**
  未変換の EMUER から引くときも、引当先としてウォレットのアドレスが要る。
  初めて来た人（無料・ウォレットなし）には、現金かカードで案内する。
- **JPYC とウォレットの EMUER は、MetaMask などが入ったブラウザでしか払えない。**
  LINE・Google で入った人は、未変換の EMUER か円になる。
- みてみるは「準備中」の止め方（`maintenance-guard.js`）から外してある。
  付けたままだと運営の4アドレス以外が1人も入れない。
  Camellia・チュートリアル・南エレベーターは、これまでどおり止めたまま。
